# Remove-Pfa2DirectoryServiceLocalGroup

## SYNOPSIS

Delete local groups

## SYNTAX

```
Remove-Pfa2DirectoryServiceLocalGroup [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-Gids <List[Int32]>]
 [-LocalDirectoryServiceId <List[String]>]
 [-LocalDirectoryServiceName <List[String]>] [-Name <String>]
 [-Sid <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes one or more local groups. The `Gids`, `Name`, or `Sid` parameter is required, but cannot be set together.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2DirectoryServiceLocalGroup -Array $FlashArray -Name 'storage-admins'
```

Deletes the local directory group named 'storage-admins'.

### Example 2
```powershell
Remove-Pfa2DirectoryServiceLocalGroup -Array $FlashArray -Name 'storage-admins' -Gids 1
```

Deletes the local directory group, also specifying -Gids.

### Example 3
```powershell
Remove-Pfa2DirectoryServiceLocalGroup -Array $FlashArray -Name 'storage-admins' -LocalDirectoryServiceName 'directory-service-01'
```

Deletes the local directory group, also specifying -LocalDirectoryServiceName.
