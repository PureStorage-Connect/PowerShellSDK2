# New-Pfa2VchostCertificate

## SYNOPSIS

Create a vchost certificate

## SYNTAX

```
New-Pfa2VchostCertificate [-Array <Rest2Api>] [-XRequestID <String>]
 [-VchostId <List[String]>]
 [-VchostName <List[String]>]
 [-Endpoint <List[String]>] [-CertificateName <String>]
 [-CertificateResourceType <String>] [-ApiVersion <String>]
 [<CommonParameters>]
```

## DESCRIPTION

Creates an association between a certificate and vchost on one or more endpoints. The `VchostName` or `VchostId` query parameter is required.

## EXAMPLES

### Example 1
```powershell
New-Pfa2VchostCertificate -Array $FlashArray -VchostName 'vchost-01' -Endpoint 'vchost-01-endpoint' -CertificateName 'management'
```

Creates a vchost certificate on the array.

### Example 2
```powershell
New-Pfa2VchostCertificate -Array $FlashArray -VchostName 'vchost-01'
```

Creates a vchost certificate specifying only -VchostName.
