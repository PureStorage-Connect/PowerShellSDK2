# Update-Pfa2ContainerDefaultProtection

## SYNOPSIS

Modify a container's default protections

## SYNTAX

```
Update-Pfa2ContainerDefaultProtection [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-Id <List[String]>] [-Name <String>]
 [-DefaultProtectionsId <List[String]>]
 [-DefaultProtectionsName <List[String]>]
 [-DefaultProtectionsType <List[String]>] [-DefaultProtectionsReset]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies a container's default protections. To modify, set `default_protections` to the new list.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2ContainerDefaultProtection -Array $FlashArray -Name 'prod-pod' -DefaultProtectionsName 'default-protections-01'
```

Sets -DefaultProtectionsName on the container default protection named 'prod-pod'.

### Example 2
```powershell
Update-Pfa2ContainerDefaultProtection -Array $FlashArray -Name 'prod-pod' -DefaultProtectionsType 'prod-pod'
```

Sets -DefaultProtectionsType on the container default protection named 'prod-pod'.

### Example 3
```powershell
Update-Pfa2ContainerDefaultProtection -Array $FlashArray -Name 'prod-pod' -DefaultProtectionsReset
```

Sets -DefaultProtectionsReset on the container default protection named 'prod-pod'.
