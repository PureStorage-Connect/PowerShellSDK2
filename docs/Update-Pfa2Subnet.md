# Update-Pfa2Subnet

## SYNOPSIS

(REST API 2.2+) Modify subnet

## SYNTAX

```
Update-Pfa2Subnet [-Array <Rest2Api>] [-XRequestID <String>] [-Name <String>] [-SubnetName <String>]
 [-Enabled <Boolean>] [-Gateway <String>] [-Mtu <Int32>] [-Prefix <String>] [-Vlan <Int32>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies one or more specified subnet properties.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2Subnet -Array $FlashArray -Name $Name -Enabled $false -Vlan $Vlan
```

Find a subnet of FlashArray by name and update with specific parameters.

### Example 2
```powershell
Update-Pfa2Subnet -Array $FlashArray -Name 'replication-subnet' -SubnetName 'replication-subnet-renamed'
```

Renames the subnet 'replication-subnet' to 'replication-subnet-renamed'.

### Example 3
```powershell
Update-Pfa2Subnet -Array $FlashArray -Name 'replication-subnet' -Enabled $true
```

Sets -Enabled on the subnet named 'replication-subnet'.

### Example 4
```powershell
Update-Pfa2Subnet -Array $FlashArray -Name 'replication-subnet' -Gateway '10.0.1.1'
```

Sets -Gateway on the subnet named 'replication-subnet'.
