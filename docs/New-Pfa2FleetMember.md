# New-Pfa2FleetMember

## SYNOPSIS

Add members to a fleet

## SYNTAX

```
New-Pfa2FleetMember [-Array <Rest2Api>] [-XRequestID <String>]
 [-FleetId <List[String]>]
 [-FleetName <List[String]>]
 [-MemberKey <List[String]>]
 [-MemberId <List[String]>]
 [-MemberName <List[String]>]
 [-MemberResourceType <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Adds arrays to an existing fleet. This API needs to be run from the array that's joining the fleet.  To add the current array to the fleet, specify its own array `MemberId` or `MemberName`, as well as the `fleet key` generated on any array already in the fleet. `MemberResourceType` is `remote-arrays`. The array's `ID` and `MemberName` can be retrieved with a call to `Get-Pfa2FleetMember /arrays` on the array.

## EXAMPLES

### Example 1
```powershell
New-Pfa2FleetMember -Array $FlashArray -FleetName 'prod-fleet' -MemberName 'array2'
```

Adds remote array 'array2' to fleet 'prod-fleet'.

### Example 2
```powershell
New-Pfa2FleetMember -Array $FlashArray -FleetName 'prod-fleet' -MemberName 'array2', 'array3'
```

Adds several remote arrays to fleet 'prod-fleet' in a single call.
