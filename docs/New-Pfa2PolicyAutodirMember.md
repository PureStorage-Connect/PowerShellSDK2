# New-Pfa2PolicyAutodirMember

## SYNOPSIS

Create auto managed directory policies

## SYNTAX

```
New-Pfa2PolicyAutodirMember [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-PolicyId <List[String]>]
 [-PolicyName <List[String]>]
 [-MemberId <List[String]>]
 [-MemberName <List[String]>]
 [-MemberResourceType <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a membership between one or more resources with an auto managed directory policy. Applicable resources are directories. The `PolicyId` or `PolicyName` parameter is required, but they cannot be set together.

## EXAMPLES

### Example 1
```powershell
New-Pfa2PolicyAutodirMember -Array $FlashArray -PolicyName 'autodir-default' -MemberName 'fs-prod-01:home'
```

Adds managed directory 'fs-prod-01:home' to auto-directory policy 'autodir-default'.

### Example 2
```powershell
New-Pfa2PolicyAutodirMember -Array $FlashArray -PolicyName 'autodir-default' -MemberName 'fs-prod-01:home', 'fs-prod-02:home'
```

Adds several managed directories to auto-directory policy 'autodir-default' in a single call.
