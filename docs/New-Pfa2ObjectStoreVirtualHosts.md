# New-Pfa2ObjectStoreVirtualHosts

## SYNOPSIS

(REST API 2.26+) Create an object store virtual host

## SYNTAX

```
New-Pfa2ObjectStoreVirtualHosts [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] -Name <String> [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Registers a virtual host name for the object store so clients can use virtual-hosted-style bucket addressing.

## EXAMPLES

### Example 1
```powershell
New-Pfa2ObjectStoreVirtualHosts -Array $FlashArray -Name 's3.example.com'
```

Registers a virtual host name so clients can address buckets as <bucket>.s3.example.com.

### Example 2
```powershell
Get-Pfa2ObjectStoreVirtualHosts -Array $FlashArray
```

Lists the virtual host names already registered.
