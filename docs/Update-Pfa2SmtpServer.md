# Update-Pfa2SmtpServer

## SYNOPSIS

(REST API 2.4+) Modify SMTP server attributes

## SYNTAX

```
Update-Pfa2SmtpServer [-Array <Rest2Api>] [-XRequestID <String>] [-BodyPrefix <String>]
 [-EncryptionMode <String>] [-Password <SecureString>] [-RelayHost <String>] [-SenderDomain <String>]
 [-SenderUsername <String>] [-SubjectPrefix <String>] [-UserName <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies SMTP server attributes. Values include `UserName`, `Password`, `RelayHost`, `SenderDomain`, `SenderUsername`, `SubjectPrefix`, `BodyPrefix`, `EncryptionMode`, and `SmtpName`.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2SmtpServer -Array $FlashArray -BodyPrefix 'smtp.example.com'
```

Sets -BodyPrefix on the SMTP relay configuration.

### Example 2
```powershell
Update-Pfa2SmtpServer -Array $FlashArray -EncryptionMode 'smtp.example.com'
```

Sets -EncryptionMode on the SMTP relay configuration.

### Example 3
```powershell
Update-Pfa2SmtpServer -Array $FlashArray -Password $SecurePassword
```

Sets -Password on the SMTP relay configuration.
