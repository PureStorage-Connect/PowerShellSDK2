# New-Pfa2DirectoryPolicyUserGroupQuota

## SYNOPSIS

Create a membership between a directory and one or more user-group-quota policies

## SYNTAX

```
New-Pfa2DirectoryPolicyUserGroupQuota [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-IgnoreUsage <Boolean>]
 [-MemberId <List[String]>]
 [-MemberName <List[String]>]
 [-PolicyId <List[String]>]
 [-PolicyName <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a membership between a directory and one or more user-group-quota policies. The `MemberId` or `MemberName` parameter is required, but cannot be set together.

## EXAMPLES

### Example 1
```powershell
New-Pfa2DirectoryPolicyUserGroupQuota -Array $FlashArray -PolicyName 'group-quota-01' -MemberName 'user-quota-1t'
```

Adds user and group quota policy 'user-quota-1t' to managed directory 'fs-prod-01:home'.

### Example 2
```powershell
New-Pfa2DirectoryPolicyUserGroupQuota -Array $FlashArray -PolicyName 'group-quota-01' -MemberName 'user-quota-1t', 'user-quota-2t'
```

Adds several user and group quota policies to managed directory 'fs-prod-01:home' in a single call.
