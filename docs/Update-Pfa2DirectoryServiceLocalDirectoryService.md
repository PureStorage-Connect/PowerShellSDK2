# Update-Pfa2DirectoryServiceLocalDirectoryService

## SYNOPSIS

Modify local directory service

## SYNTAX

```
Update-Pfa2DirectoryServiceLocalDirectoryService [-Array <Rest2Api>] [-XRequestID <String>]
 [-Id <List[String]>] [-Name <String>]
 [-ToMemberId <List[String]>]
 [-ToMemberName <List[String]>] [-LocalDirectoryName <String>]
 [-Domain <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies local directory services.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2DirectoryServiceLocalDirectoryService -Array $FlashArray -Name 'management' -Domain 'example.com'
```

Sets -Domain on the local directory service named 'management'.

### Example 2
```powershell
Update-Pfa2DirectoryServiceLocalDirectoryService -Array $FlashArray -Name 'management' -ToMemberName 'esx-cluster-02'
```

Sets -ToMemberName on the local directory service named 'management'.

### Example 3
```powershell
Update-Pfa2DirectoryServiceLocalDirectoryService -Array $FlashArray -Name 'management' -LocalDirectoryName 'local-directory-01'
```

Sets -LocalDirectoryName on the local directory service named 'management'.
