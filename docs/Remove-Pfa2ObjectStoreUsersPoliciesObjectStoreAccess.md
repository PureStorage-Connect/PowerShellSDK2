# Remove-Pfa2ObjectStoreUsersPoliciesObjectStoreAccess

## SYNOPSIS

(REST API 2.26+) Detach an object store access policy from a user

## SYNTAX

```
Remove-Pfa2ObjectStoreUsersPoliciesObjectStoreAccess [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-MemberId <List[String]>]
 [-MemberName <List[String]>]
 [-PolicyId <List[String]>]
 [-PolicyName <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Detaches one or more object store access policies from an object store user.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2ObjectStoreUsersPoliciesObjectStoreAccess -Array $FlashArray -PolicyName 'bucket-read-only' -MemberName 's3-account-01/reporting-user'
```

Removes object store user 's3-account-01/reporting-user' from object store access policy 'bucket-read-only'. The object store user itself is not deleted.

### Example 2
```powershell
Get-Pfa2ObjectStoreUsersPoliciesObjectStoreAccess -Array $FlashArray -PolicyName 'bucket-read-only' | ForEach-Object { Remove-Pfa2ObjectStoreUsersPoliciesObjectStoreAccess -Array $FlashArray -PolicyName 'bucket-read-only' -MemberName $_.Member.Name }
```

Removes every current member of object store access policy 'bucket-read-only'.
