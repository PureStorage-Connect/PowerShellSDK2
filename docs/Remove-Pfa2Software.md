# Remove-Pfa2Software

## SYNOPSIS

(REST API 2.11+) Delete a software package

## SYNTAX

```
Remove-Pfa2Software [-Array <Rest2Api>] [-XRequestID <String>] [-Name <String>]
 [-SoftwareVersion <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes a software package specified by software name and version. A software package being used for an installation can be deleted if the installation is `downloading`, `downloaded`, `aborted`, or `finished`. If the software package is currently `downloading`, the download will be cancelled.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2Software -Array $FlashArray -Name 'purity//fa'
```

Deletes the software package named 'purity//fa'.

### Example 2
```powershell
Remove-Pfa2Software -Array $FlashArray -Name 'purity//fa' -SoftwareVersion '6.8.4'
```

Deletes the software package, also specifying -SoftwareVersion.
