# Update-Pfa2Bucket

## SYNOPSIS

(REST API 2.26+) Modify a bucket

## SYNTAX

```
Update-Pfa2Bucket [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-Id <List[String]>] [-Name <String>] [-Destroyed <Boolean>]
 [-Versioning <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies an object store bucket. Use this to change the versioning state, to destroy the bucket, or to recover a bucket that is pending eradication by setting `Destroyed` to `$False`.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2Bucket -Array $FlashArray -Name 'analytics-bucket' -Versioning 'analytics-bucket'
```

Sets -Versioning on the bucket named 'analytics-bucket'.

### Example 2
```powershell
Update-Pfa2Bucket -Array $FlashArray -Name 'analytics-bucket' -Destroyed $true
```

Destroys the bucket named 'analytics-bucket'. The object enters the eradication pending state and can be recovered with `-Destroyed $false` until that period expires.

### -Destroyed

If set to `$True`, lists only destroyed objects that are in the eradication pending state. If set to `$False`, lists only objects that are not destroyed. If not set, lists both objects that are destroyed and those that are not destroyed. For destroyed objects, the time remaining is displayed in milliseconds.  If object name(s) or id(s) are specified, then each object referenced must exist. If `Destroyed` is set to `$True`, then each object referenced must also be destroyed. If `Destroyed` is set to `$False`, then each object referenced must also not be destroyed. An error is returned if any of these conditions are not met.
