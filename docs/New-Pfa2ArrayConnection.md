# New-Pfa2ArrayConnection

## SYNOPSIS

(REST API 2.4+) Create an array connection

## SYNTAX

```
New-Pfa2ArrayConnection [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-ConnectionKey <String>]
 [-Encryption <String>] [-ManagementAddress <String>]
 [-ReplicationAddress <List[String]>] [-ReplicationTransport <String>]
 [-Type <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a connection between this array and the specified array.

## EXAMPLES

### Example 1
```powershell
New-Pfa2ArrayConnection -Array $FlashArray -ManagementAddress '10.0.2.10' -ConnectionKey $ConnectionKey -Type 'replication'
```

Connects this array to a peer for replication, using the key returned by Get-Pfa2ArrayConnectionKey on the peer.

### Example 2
```powershell
New-Pfa2ArrayConnection -Array $FlashArray -ManagementAddress '10.0.2.10' -ConnectionKey $ConnectionKey -Type 'replication' -ReplicationAddress '10.0.3.10' -Encryption 'encrypted'
```

Connects two arrays over a dedicated replication address with the replication traffic encrypted.

### Example 3
```powershell
New-Pfa2ArrayConnection -Array $FlashArray -ConnectionKey $ConnectionKey -Encryption 'encrypted' -ManagementAddress '10.0.2.10'
```

Creates an array connection on the array.

### Example 4
```powershell
New-Pfa2ArrayConnection -Array $FlashArray -ConnectionKey $ConnectionKey
```

Creates an array connection specifying only -ConnectionKey.
