# Remove-Pfa2ArrayCloudProviderTag

## SYNOPSIS

(REST API 2.6+) Delete user tags from the cloud.

## SYNTAX

```
Remove-Pfa2ArrayCloudProviderTag [-Array <Rest2Api>] [-XRequestID <String>]
 [-Key <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes user tags from deployed cloud resources of a CBS array.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2ArrayCloudProviderTag -Array $FlashArray -Key 'environment'
```

Removes the `environment` tag from the array.

### Example 2
```powershell
Remove-Pfa2ArrayCloudProviderTag -Array $FlashArray -Key 'environment', 'owner'
```

Removes several tags from the array in one call.
