# New-Pfa2Kmip

## SYNOPSIS

(REST API 2.2+) Create KMIP server object

## SYNTAX

```
New-Pfa2Kmip [-Array <Rest2Api>] [-XRequestID <String>] [-Name <String>] [-CaCertificate <String>]
 [-Uri <List[String]>] [-CertificateName <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates KMIP server objects.

## EXAMPLES

### Example 1
```powershell
New-Pfa2Kmip -Array $FlashArray -Name 'kmip-server-01' -Uri 'kmip-server-01.example.com' -CertificateName 'management' -CaCertificate $CaCertificatePem
```

Registers a KMIP server for external key management. The array certificate is referenced by name with -CertificateName; earlier releases used -Certificate.

### Example 2
```powershell
New-Pfa2Kmip -Array $FlashArray -Name 'kmip-server-01' -Uri 'kmip-server-01.example.com:5696' -CertificateName 'management'
```

Registers a KMIP server on a non-default port.

### Example 3
```powershell
New-Pfa2Kmip -Array $FlashArray -Name 'kmip-server-01'
```

Creates a KMIP server named 'kmip-server-01'.

### Example 4
```powershell
New-Pfa2Kmip -Array $FlashArray -Name 'kmip-server-01' -CaCertificate $CaCertificatePem -Uri 'kmip-server-01.example.com'
```

Creates a KMIP server and sets -CaCertificate and -Uri in the same call.
