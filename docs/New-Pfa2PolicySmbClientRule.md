# New-Pfa2PolicySmbClientRule

## SYNOPSIS

(REST API 2.3+) Create SMB client policy rules

## SYNTAX

```
New-Pfa2PolicySmbClientRule [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-PolicyId <List[String]>]
 [-PolicyName <List[String]>]
 [-RulesAnonymousAccessAllowed <List[Boolean]>]
 [-RulesClient <List[String]>]
 [-RulesSmbEncryptionRequired <List[Boolean]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates one or more SMB client policy rules. The `PolicyId` or `PolicyName` parameter is required, but cannot be set together.

## EXAMPLES

### Example 1
```powershell
New-Pfa2PolicySmbClientRule -Array $FlashArray -PolicyName 'smb-default' -RulesClient '10.0.0.0/24' -RulesSmbEncryptionRequired $true
```

Adds an SMB client rule that requires encryption for a subnet.

### Example 2
```powershell
New-Pfa2PolicySmbClientRule -Array $FlashArray -PolicyName 'smb-default' -RulesClient '*' -RulesAnonymousAccessAllowed $false
```

Adds a catch-all rule that denies anonymous access.

### Example 3
```powershell
New-Pfa2PolicySmbClientRule -Array $FlashArray -PolicyName 'smb-default'
```

Creates an SMB policy client rule specifying only -PolicyName.
