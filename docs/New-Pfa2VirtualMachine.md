# New-Pfa2VirtualMachine

## SYNOPSIS

(REST API 2.10+) Create a virtual machine

## SYNTAX

```
New-Pfa2VirtualMachine [-Array <Rest2Api>] [-XRequestID <String>] [-Overwrite <Boolean>] [-Id <String>]
 [-VmId <String>] [-VmType <String>] [-SourceId <String>] [-SourceName <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates one or more virtual machines from a protection group snapshot. If the virtual machine is of type `vvol`, the `source` property of the request body must be a `recovery_context` value retrieved from the `Get-Pfa2VirtualMachine /virtual-machine-snapshots` endpoint. If `Overwrite` is specified, an existing virtual machine will have its volumes overwritten by the snapshot. Otherwise, a new virtual machine will be created from the snapshot. If creating the new virtual machine will cause a conflict with an existing virtual machine, the operation will fail.

## EXAMPLES

### Example 1
```powershell
New-Pfa2VirtualMachine -Array $FlashArray -VmId 'vm-501' -VmType 'vvol' -SourceName 'vm-01'
```

Recovers a vVol virtual machine from a managed snapshot.

### Example 2
```powershell
New-Pfa2VirtualMachine -Array $FlashArray -VmId 'vm-501' -VmType 'vvol' -SourceName 'vm-01' -Overwrite $true
```

Recovers a vVol virtual machine, overwriting the existing one.

### Example 3
```powershell
New-Pfa2VirtualMachine -Array $FlashArray -VmType 'vvol' -SourceName 'vm-01' -Overwrite $true
```

Creates a virtual machine on the array.

### Example 4
```powershell
New-Pfa2VirtualMachine -Array $FlashArray -VmType 'vvol'
```

Creates a virtual machine specifying only -VmType.
