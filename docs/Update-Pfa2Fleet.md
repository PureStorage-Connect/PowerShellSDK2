# Update-Pfa2Fleet

## SYNOPSIS

Modify a fleet

## SYNTAX

```
Update-Pfa2Fleet [-Array <Rest2Api>] [-XRequestID <String>]
 [-Id <List[String]>] [-Name <String>] [-FleetName <String>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies a fleet, changing its name by passing the old name in `FleetName` query parameter, and the new name in the `FleetName` parameter in the request body.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2Fleet -Array $FlashArray -Name 'prod-fleet' -FleetName 'production-fleet'
```

Renames a fleet.

### Example 2
```powershell
Get-Pfa2Fleet -Array $FlashArray | Format-Table Name, Id -AutoSize
```

Lists the fleets this array belongs to.
