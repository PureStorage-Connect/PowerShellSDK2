# New-Pfa2Admin

## SYNOPSIS

(REST API 2.2+) Create an administrator

## SYNTAX

```
New-Pfa2Admin [-Array <Rest2Api>] [-XRequestID <String>] [-Name <String>] [-Password <SecureString>]
 [-ManagementAccessPoliciesId <List[String]>]
 [-ManagementAccessPoliciesName <List[String]>]
 [-ManagementAccessPoliciesResourceType <List[String]>]
 [-RoleName <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates an administrator.

## EXAMPLES

### Example 1
```powershell
New-Pfa2Admin -Array $FlashArray -Name 'jsmith' -Password $SecurePassword -RoleName 'array_admin'
```

Creates a local array administrator in the array_admin role. The role is set with -RoleName; earlier releases used -Role.

### Example 2
```powershell
New-Pfa2Admin -Array $FlashArray -Name 'jsmith'
```

Creates an array administrator named 'jsmith'.

### Example 3
```powershell
New-Pfa2Admin -Array $FlashArray -Name 'jsmith' -Password $SecurePassword -ManagementAccessPoliciesName 'pure:policy/array-admin'
```

Creates an array administrator and sets -Password and -ManagementAccessPoliciesName in the same call.
