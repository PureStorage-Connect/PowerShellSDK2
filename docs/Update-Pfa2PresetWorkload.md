# Update-Pfa2PresetWorkload

## SYNOPSIS

Modify a workload preset

## SYNTAX

```
Update-Pfa2PresetWorkload [-Array <Rest2Api>] [-XRequestId <String>]
 [-ContextName <List[String]>]
 [-Id <List[String]>] [-Name <String>] [-PresetName <String>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies a workload preset by overriding the fields specified in `preset`. To rename a workload preset, set name to the new name.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2PresetWorkload -Array $FlashArray -Name 'sql-server-preset' -PresetName 'sql-server-preset-v2'
```

Renames a workload preset.

### Example 2
```powershell
Get-Pfa2PresetWorkload -Array $FlashArray | Format-Table Name, WorkloadType -AutoSize
```

Lists the workload presets available on the array.
