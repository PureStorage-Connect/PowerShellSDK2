# Remove-Pfa2Dns

## SYNOPSIS

(REST API 2.15+) Delete DNS configuration

## SYNTAX

```
Remove-Pfa2Dns [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-Name <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes DNS configuration identified by configuration name.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2Dns -Array $FlashArray -Name 'management'
```

Deletes the DNS configuration named 'management'.

### Example 2
```powershell
Get-Pfa2Dns -Array $FlashArray -Filter "name='management*'" | Remove-Pfa2Dns -Array $FlashArray
```

Deletes every DNS configuration returned by the filter by piping the results into Remove-Pfa2Dns.
