# Get-Pfa2ArrayNtpTest

## SYNOPSIS

(REST API 2.2+) List NTP test results

## SYNTAX

```
Get-Pfa2ArrayNtpTest [-Array <Rest2Api>] [-XRequestID <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Displays test results for configured NTP servers.

## EXAMPLES

### Example 1
```powershell
Get-Pfa2ArrayNtpTest -Array $FlashArray
```

Tests whether the array can reach its configured NTP servers and returns a result per server.

### Example 2
```powershell
Get-Pfa2ArrayNtpTest -Array $FlashArray | Where-Object { -not $_.Success }
```

Returns only the NTP checks that failed.
