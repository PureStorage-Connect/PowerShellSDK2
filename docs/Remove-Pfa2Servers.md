# Remove-Pfa2Servers

## SYNOPSIS

Delete server

## SYNTAX

```
Remove-Pfa2Servers [-Array <Rest2Api>] [-XRequestId <String>]
 [-CascadeDelete <List[String]>]
 [-Id <List[String]>] [-Name <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes a server.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2Servers -Array $FlashArray -Name 'server-01'
```

Deletes the server named 'server-01'.

### Example 2
```powershell
Remove-Pfa2Servers -Array $FlashArray -Name 'server-01' -CascadeDelete 'server-01'
```

Deletes the server, also specifying -CascadeDelete.
