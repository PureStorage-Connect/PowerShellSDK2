# New-Pfa2Servers

## SYNOPSIS

Create server

## SYNTAX

```
New-Pfa2Servers [-Array <Rest2Api>] [-XRequestId <String>] [-CreateLocalDirectoryService <String>]
 [-Name <String>] [-DirectoryServiceId <List[String]>]
 [-DirectoryServiceName <List[String]>]
 [-DnsId <List[String]>]
 [-DnsName <List[String]>] [-LocalDirectoryServiceId <String>]
 [-LocalDirectoryServiceName <String>] [-ApiVersion <String>]
 [<CommonParameters>]
```

## DESCRIPTION

Creates a server on the local array. The server must be given a unique name.

## EXAMPLES

### Example 1
```powershell
New-Pfa2Servers -Array $FlashArray -Name 'server-01'
```

Creates a server named 'server-01'.

### Example 2
```powershell
New-Pfa2Servers -Array $FlashArray -Name 'server-01' -CreateLocalDirectoryService 'server-01' -DirectoryServiceName 'management'
```

Creates a server and sets -CreateLocalDirectoryService and -DirectoryServiceName in the same call.
