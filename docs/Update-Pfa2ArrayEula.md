# Update-Pfa2ArrayEula

## SYNOPSIS

(REST API 2.2+) Modify signature on the End User Agreement

## SYNTAX

```
Update-Pfa2ArrayEula [-Array <Rest2Api>] [-XRequestID <String>] [-SignatureCompany <String>]
 [-SignatureName <String>] [-SignatureTitle <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies the signature on the End User Agreement.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2ArrayEula -Array $FlashArray -SignatureName 'Jane Smith' -SignatureTitle 'Storage Administrator' -SignatureCompany 'Example Corp'
```

Accepts the end user license agreement. The signature is now supplied as the individual -Signature* parameters rather than as an object.

### Example 2
```powershell
Get-Pfa2ArrayEula -Array $FlashArray | Select-Object -ExpandProperty Signature
```

Shows the signature currently recorded against the EULA.

### Example 3
```powershell
Update-Pfa2ArrayEula -Array $FlashArray -SignatureCompany 'Example Corp'
```

Sets -SignatureCompany on the end user license agreement.

### Example 4
```powershell
Update-Pfa2ArrayEula -Array $FlashArray -SignatureName 'Jane Smith'
```

Sets -SignatureName on the end user license agreement.
