# New-Pfa2ProtectionGroupHost

## SYNOPSIS

(REST API 2.1+) Create an action to add a host to a protection group

## SYNTAX

```
New-Pfa2ProtectionGroupHost [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-GroupId <List[String]>]
 [-GroupName <List[String]>]
 [-MemberName <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates an action to add a host member to a protection group. Members that are already in the protection group are not affected. For asynchronous replication, only members of the same type can belong to a protection group. The `GroupName` parameter represents the name of the protection group, and the `MemberName` parameter represents the name of the host. The `GroupName` and `MemberName` parameters are required and must be set together.

## EXAMPLES

### Example 1
```powershell
New-Pfa2ProtectionGroupHost -Array $FlashArray -GroupName $ProtectionGroupName -MemberName $NewHost.Name
```

Add a host $NewHost.Name to protection group $ProtectionGroupName.

### Example 2
```powershell
New-Pfa2ProtectionGroupHost -Array $FlashArray -GroupName 'db-daily-pg' -MemberName 'esx-host-01', 'esx-host-02'
```

Adds several hosts to protection group 'db-daily-pg' in a single call.
