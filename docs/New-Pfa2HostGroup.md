# New-Pfa2HostGroup

## SYNOPSIS

(REST API 2.0+) Create a host group and upsert tags

## SYNTAX

```
New-Pfa2HostGroup [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-Name <String>]
 [-QosBandwidthLimit <Int64>] [-QosIopsLimit <Int64>]
 [-TagKey <List[String]>]
 [-TagNamespace <List[String]>]
 [-TagValue <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a host group in which the `Name` query parameter is required.

## EXAMPLES

### Example 1
```powershell
New-Pfa2HostGroup -Array $FlashArray -Name 'esx-cluster-01'
```

Creates a host group named 'esx-cluster-01'.

### Example 2
```powershell
New-Pfa2HostGroup -Array $FlashArray -Name 'esx-cluster-01' -QosBandwidthLimit 512MB -QosIopsLimit 10000
```

Creates a host group and sets -QosBandwidthLimit and -QosIopsLimit in the same call.

### Example 3
```powershell
New-Pfa2HostGroup -Array $FlashArray -Name 'esx-cluster-01' -TagKey 'environment' -TagValue 'production'
```

Creates a host group and applies the tag `environment=production`.
