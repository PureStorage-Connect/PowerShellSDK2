# Update-Pfa2Directory

## SYNOPSIS

(REST API 2.3+) Modify a managed directory

## SYNTAX

```
Update-Pfa2Directory [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-Id <List[String]>] [-Name <String>] [-DirectoryName <String>]
 [-WorkloadId <String>] [-WorkloadName <String>] [-ApiVersion <String>]
 [<CommonParameters>]
```

## DESCRIPTION

Modifies a managed directory. To rename a managed directory, set `name` to the new name. The `Id` or `Name` parameter is required, but cannot be set together. The `name` or `DirectoryName` parameter is required.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2Directory -Array $FlashArray -Name 'fs-prod-01:home' -DirectoryName 'fs-prod-01:home-renamed'
```

Renames the managed directory 'fs-prod-01:home' to 'fs-prod-01:home-renamed'.

### Example 2
```powershell
Update-Pfa2Directory -Array $FlashArray -Name 'fs-prod-01:home' -WorkloadName 'sql-prod-workload'
```

Sets -WorkloadName on the managed directory named 'fs-prod-01:home'.
