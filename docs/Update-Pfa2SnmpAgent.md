# Update-Pfa2SnmpAgent

## SYNOPSIS

(REST API 2.4+) Modify SNMP agent

## SYNTAX

```
Update-Pfa2SnmpAgent [-Array <Rest2Api>] [-XRequestID <String>] [-Version <String>] [-V2cCommunity <String>]
 [-V3AuthPassphrase <String>] [-V3AuthProtocol <String>] [-V3PrivacyPassphrase <String>]
 [-V3PrivacyProtocol <String>] [-V3User <String>] [-ApiVersion <String>]
 [<CommonParameters>]
```

## DESCRIPTION

Modifies the name or the protocol attributes of the SNMP agent.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2SnmpAgent -Array $FlashArray -Version '6.8.4'
```

Sets -Version on the SNMP agent.

### Example 2
```powershell
Update-Pfa2SnmpAgent -Array $FlashArray -V2cCommunity 'snmp-agent'
```

Sets -V2cCommunity on the SNMP agent.

### Example 3
```powershell
Update-Pfa2SnmpAgent -Array $FlashArray -V3AuthPassphrase 'snmp-agent'
```

Sets -V3AuthPassphrase on the SNMP agent.
