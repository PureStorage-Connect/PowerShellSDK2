# Update-Pfa2VolumeSnapshot

## SYNOPSIS

(REST API 2.0+) Modify a volume snapshot

## SYNTAX

```
Update-Pfa2VolumeSnapshot [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-Id <List[String]>] [-Name <String>] [-ReplicationSnapshot <Boolean>]
 [-Destroyed <Boolean>] [-VolumeSnapshotName <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies a volume snapshot by renaming, destroying, or recovering it. To rename the suffix of a volume snapshot, set `VolumeSnapshotName` to the new suffix name. To recover a volume snapshot that has been destroyed and is pending eradication, set `Destroyed=$True`. The `Id` or `Name` parameter is required, but they cannot be set together.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2VolumeSnapshot -Array $FlashArray -Name $VolumeSnapshot.Name -VolumeSnapshotName $NewSuffix
```

Update a volume snapshot name to $NewSuffix on FlashArray.

### Example 2
```powershell
Update-Pfa2VolumeSnapshot -Array $FlashArray -Destroyed $true -Name $VolumeSnapshot.Name
```

Destroy a volume snapshot for snapshot $VolumeSnapshot.Name.

### Example 3
```powershell
Update-Pfa2VolumeSnapshot -Array $FlashArray -Name 'db-vol-01.daily' -ReplicationSnapshot $true
```

Sets -ReplicationSnapshot on the volume snapshot named 'db-vol-01.daily'.
