# Remove-Pfa2AdminApiToken

## SYNOPSIS

(REST API 2.2+) Delete API tokens

## SYNTAX

```
Remove-Pfa2AdminApiToken [-Array <Rest2Api>] [-XRequestID <String>] [-Name <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes the API tokens of the specified administrators.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2AdminApiToken -Array $FlashArray -Name $Name
```

Remove API token of array admin $Name.

### Example 2
```powershell
Get-Pfa2AdminApiToken -Array $FlashArray -Filter "name='jsmith*'" | Remove-Pfa2AdminApiToken -Array $FlashArray
```

Deletes every administrator API token returned by the filter by piping the results into Remove-Pfa2AdminApiToken.
