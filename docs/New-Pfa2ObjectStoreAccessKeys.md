# New-Pfa2ObjectStoreAccessKeys

## SYNOPSIS

(REST API 2.26+) Create an object store access key

## SYNTAX

```
New-Pfa2ObjectStoreAccessKeys [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-UserId <String>] [-UserName <String>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates an S3 access key and secret access key for an object store user. The secret access key is returned only in the response to this call and cannot be retrieved afterwards, so capture it when the key is created.

## EXAMPLES

### Example 1
```powershell
New-Pfa2ObjectStoreAccessKeys -Array $FlashArray -UserName 's3-account-01/reporting-user'
```

Issues an S3 access key and secret for an object store user. The secret is returned only once, so capture it now.

### Example 2
```powershell
$Key = New-Pfa2ObjectStoreAccessKeys -Array $FlashArray -UserName 's3-account-01/reporting-user'; $Key.Name; $Key.SecretAccessKey
```

Issues an access key and returns the key ID and secret.
