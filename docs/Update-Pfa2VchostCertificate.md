# Update-Pfa2VchostCertificate

## SYNOPSIS

Modify a vchost certificate

## SYNTAX

```
Update-Pfa2VchostCertificate [-Array <Rest2Api>] [-XRequestID <String>]
 [-CertificateName <List[String]>]
 [-Id <List[String]>]
 [-VchostId <List[String]>]
 [-VchostName <List[String]>]
 [-Endpoint <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies an existing vchost certificate. The `Id` query parameter alone, or the `CertificateName` query parameter together with one of `VchostName` or `VchostId`, is required.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2VchostCertificate -Array $FlashArray -CertificateName 'management'
```

Sets -CertificateName on the vchost certificate.

### Example 2
```powershell
Update-Pfa2VchostCertificate -Array $FlashArray -Endpoint 'vchost-01-endpoint'
```

Sets -Endpoint on the vchost certificate.
