# Remove-Pfa2Bucket

## SYNOPSIS

(REST API 2.26+) Delete or eradicate a bucket

## SYNTAX

```
Remove-Pfa2Bucket [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-Id <List[String]>] [-Name <String>] [-Eradicate] [-ApiVersion <String>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Destroys an object store bucket, or eradicates one that is already destroyed when `Eradicate` is specified. Eradication is permanent and cannot be undone.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2Bucket -Array $FlashArray -Name 'analytics-bucket' -Confirm:$false
```

Deletes the bucket named 'analytics-bucket'.

### Example 2
```powershell
Remove-Pfa2Bucket -Array $FlashArray -Name 'analytics-bucket' -Eradicate -Confirm:$false
```

Permanently eradicates the destroyed bucket named 'analytics-bucket'. This bypasses the eradication pending period and cannot be undone.

### Example 3
```powershell
Get-Pfa2Bucket -Array $FlashArray -Destroyed $true | Remove-Pfa2Bucket -Array $FlashArray -Eradicate -Confirm:$false
```

Eradicates every bucket that is already destroyed and pending eradication.
