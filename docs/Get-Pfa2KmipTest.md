# Get-Pfa2KmipTest

## SYNOPSIS

(REST API 2.2+) Lists KMIP connection tests

## SYNTAX

```
Get-Pfa2KmipTest [-Array <Rest2Api>] [-XRequestID <String>] -Name <String> [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Displays communication data between a FlashArray and KMIP server.

## EXAMPLES

### Example 1
```powershell
Get-Pfa2KmipTest -Array $testarray -Name $kmipName
```

Test KMIP server previously configured using name $kmipName.

### Example 2
```powershell
Get-Pfa2KmipTest -Array $FlashArray
```

Lists all KMIP server tests on the array.
