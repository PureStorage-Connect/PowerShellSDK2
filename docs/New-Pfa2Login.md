# New-Pfa2Login

## SYNOPSIS

(REST API 2.0+) Exchange an API token for a session token.

## SYNTAX

```
New-Pfa2Login [-Array <Rest2Api>] [-ApiToken <String>] [-XRequestID <String>] [-Password <SecureString>]
 [-Username <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a user session and returns a session token, using either the user's API token or their username and password. `ApiToken` is passed in a header, with the request body empty. Otherwise `Username` and `Password` are passed in the request body, without an `ApiToken` header.  Storing user passwords client-side is not recommended. The username-password authentication option should only be used as necessary for initial retrieval of an API token, which should be securely stored and used for all subsequent logins.

## EXAMPLES

### Example 1
```powershell
New-Pfa2Login -Array $FlashArray -Username 'pureuser' -Password $SecurePassword
```

Creates a REST session on the array from a username and password and returns the x-auth-token for it.

### Example 2
```powershell
New-Pfa2Login -Array $FlashArray -ApiToken $ApiToken
```

Creates a REST session from an API token. Connect-Pfa2Array wraps this call and is the normal way to authenticate.

### Example 3
```powershell
New-Pfa2Login -Array $FlashArray -ApiToken $ApiToken -Password $SecurePassword -Username 'pureuser'
```

Creates a login on the array.
