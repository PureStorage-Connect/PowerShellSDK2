# Remove-Pfa2DirectoryServiceRole

## SYNOPSIS

Delete group to management access policy mappings

## SYNTAX

```
Remove-Pfa2DirectoryServiceRole [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] -Name <String> [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes one or more group to management access policy mappings.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2DirectoryServiceRole -Array $FlashArray -Name 'array_admin'
```

Deletes the directory service role mapping named 'array_admin'.

### Example 2
```powershell
Get-Pfa2DirectoryServiceRole -Array $FlashArray -Filter "name='array_admin*'" | Remove-Pfa2DirectoryServiceRole -Array $FlashArray
```

Deletes every directory service role mapping returned by the filter by piping the results into Remove-Pfa2DirectoryServiceRole.
