# Update-Pfa2ApiClient

## SYNOPSIS

(REST API 2.1+) Manage an API client

## SYNTAX

```
Update-Pfa2ApiClient [-Array <Rest2Api>] [-XRequestID <String>]
 [-Id <List[String]>] [-Name <String>] [-Enabled <Boolean>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Enables or disables an API client. The `Id` or `Name` parameter is required, but they cannot be set together.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2ApiClient -Array $FlashArray -Name 'automation-client' -Enabled $true
```

Enables an API client. A client is created disabled, so this is the step that makes it usable for OAuth2 authentication.

### Example 2
```powershell
Update-Pfa2ApiClient -Array $FlashArray -Name 'automation-client' -Enabled $false
```

Disables an API client without deleting it, which immediately stops it issuing new access tokens.
