# Remove-Pfa2AdminCache

## SYNOPSIS

(REST API 2.2+) Delete cache entries

## SYNTAX

```
Remove-Pfa2AdminCache [-Array <Rest2Api>] [-XRequestID <String>] -RemoveAllEntries <Boolean>
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes all entries from the administrator cache.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2AdminCache -Array $FlashArray -RemoveAllEntries $true
```

Clears every cached directory-service administrator entry, forcing the array to re-query the directory on the next login.

### Example 2
```powershell
Get-Pfa2AdminCache -Array $FlashArray | Format-Table Name, Role, Time -AutoSize
```

Lists the cached administrator entries before clearing them.
