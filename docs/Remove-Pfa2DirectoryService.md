# Remove-Pfa2DirectoryService

## SYNOPSIS

Delete directory services configuration

## SYNTAX

```
Remove-Pfa2DirectoryService [-Array <Rest2Api>] [-XRequestID <String>]
 [-Id <List[String]>] [-Name <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes directory services configuration. Directory service configuration must not be referenced by any server nor enabled to be deleted. The built-in "management" directory service cannot be deleted.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2DirectoryService -Array $FlashArray -Name 'management'
```

Deletes the directory service configuration named 'management'.

### Example 2
```powershell
Get-Pfa2DirectoryService -Array $FlashArray -Filter "name='management*'" | Remove-Pfa2DirectoryService -Array $FlashArray
```

Deletes every directory service configuration returned by the filter by piping the results into Remove-Pfa2DirectoryService.
