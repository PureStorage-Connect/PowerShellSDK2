# Remove-Pfa2Pod

## SYNOPSIS

(REST API 2.1+) Delete a pod

## SYNTAX

```
Remove-Pfa2Pod [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-EradicateContents <Boolean>]
 [-Id <List[String]>] [-Name <String>] [-Eradicate] [-ApiVersion <String>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Deletes (eradicates) a pod that has been destroyed and is pending eradication. Eradicated pods cannot be recovered. Pods are destroyed using the `Update-Pfa2Pod` cmdlet. The `Ids` or `Name` parameter is required, but cannot be set together. If SafeMode is enabled then `Update-Pfa2Pod -DestroyContents $True -Destroyed $True` must be called first.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2Pod -Array $TargetArray -Name $RemotePodName -Eradicate -Confirm:$false
```

Eradicate a remote pod with name $RemotePodName.

### Example 2
```powershell
Remove-Pfa2Pod -Array $FlashArray -Name $Pod.Name -Eradicate -Confirm:$false -ErrorAction Stop
```

Eradicate a POD $Pod.Name (Only destroyed PODs can be eradicated)

### Example 3
```powershell
Remove-Pfa2Pod -Array $FlashArray -Name 'prod-pod' -Confirm:$false
```

Deletes the pod named 'prod-pod'.

### Example 4
```powershell
Get-Pfa2Pod -Array $FlashArray -Destroyed $true | Remove-Pfa2Pod -Array $FlashArray -Eradicate -Confirm:$false
```

Eradicates every pod that is already destroyed and pending eradication.
