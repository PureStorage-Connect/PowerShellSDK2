# New-Pfa2Bucket

## SYNOPSIS

(REST API 2.26+) Create a bucket

## SYNTAX

```
New-Pfa2Bucket [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] -Name <String> [-AccountId <String>]
 [-AccountName <String>] [-AccountResourceType <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates an object store bucket inside an object store account. The `Name` parameter is required, and the owning account must be identified with `AccountName` or `AccountId`.

## EXAMPLES

### Example 1
```powershell
New-Pfa2Bucket -Array $FlashArray -Name 'analytics-bucket' -AccountName 's3-account-01'
```

Creates a bucket inside an object store account.

### Example 2
```powershell
New-Pfa2Bucket -Array $FlashArray -Name 'analytics-bucket' -AccountName 's3-account-01' -AccountResourceType 'object-store-accounts'
```

Creates a bucket, stating the account resource type explicitly. This matters when a name could refer to more than one resource type.

### Example 3
```powershell
New-Pfa2Bucket -Array $FlashArray -Name 'analytics-bucket'
```

Creates a bucket with only the required parameters supplied.
