# Get-Pfa2PresetWorkload

## SYNOPSIS

List workload presets

## SYNTAX

```
Get-Pfa2PresetWorkload [-Array <Rest2Api>] [-XRequestId <String>]
 [-ContextName <List[String]>]
 [-Id <List[String]>] [-Name <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Displays a list of workload presets.

## EXAMPLES

### Example 1
```powershell
Get-Pfa2PresetWorkload -Array $FlashArray
```

Lists all workload presets on the array.

### Example 2
```powershell
Get-Pfa2PresetWorkload -Array $FlashArray -Name 'sql-server-preset'
```

Returns the workload preset named 'sql-server-preset'.
