# New-Pfa2ProtectionGroupTarget

## SYNOPSIS

(REST API 2.1+) Create an action to add a target to a protection group

## SYNTAX

```
New-Pfa2ProtectionGroupTarget [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-GroupId <List[String]>]
 [-GroupName <List[String]>]
 [-MemberId <List[String]>]
 [-MemberName <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates an action to add an array, pod, or offload target to a protection group. The `GroupName` parameter represents the name of the protection group. The `MemberName` parameter represents the name of the array, pod, or offload target that is being added to the protection group. The `GroupName` and `MemberName` parameters are required and must be set together.

## EXAMPLES

### Example 1
```powershell
New-Pfa2ProtectionGroupTarget -Array $FlashArray -GroupName $ProtectionGroupName -MemberName $NFSTargetName
```

Add a target $NFSTargetName to protection group $ProtectionGroupName.

### Example 2
```powershell
New-Pfa2ProtectionGroupTarget -Array $FlashArray -GroupName 'group-01'
```

Creates a protection group replication target specifying only -GroupName.
