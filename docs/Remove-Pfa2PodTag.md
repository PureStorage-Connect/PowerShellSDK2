# Remove-Pfa2PodTag

## SYNOPSIS

Delete tags

## SYNTAX

```
Remove-Pfa2PodTag [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-Key <List[String]>]
 [-Namespace <List[String]>]
 [-ResourceId <List[String]>]
 [-ResourceName <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes specified tags.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2PodTag -Array $FlashArray -ResourceName 'prod-pod' -Key 'environment' -Namespace 'default'
```

Removes the `environment` tag from pod 'prod-pod'.

### Example 2
```powershell
Remove-Pfa2PodTag -Array $FlashArray -ResourceName 'prod-pod', 'prod-pod-02' -Key 'environment' -Namespace 'default'
```

Removes the same tag from several pods at once.
