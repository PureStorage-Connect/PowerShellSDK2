# Update-Pfa2ActiveDirectory

## SYNOPSIS

(REST API 2.15+) Modify Active Directory account

## SYNTAX

```
Update-Pfa2ActiveDirectory [-Array <Rest2Api>] [-XRequestID <String>] -Name <String> [-Tls <String>]
 [-SourceId <List[String]>]
 [-SourceName <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies specified Active Directory account.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2ActiveDirectory -Array $FlashArray -Name 'ad-account-01' -Tls 'ad-account-01'
```

Sets -Tls on the Active Directory account named 'ad-account-01'.

### Example 2
```powershell
Update-Pfa2ActiveDirectory -Array $FlashArray -Name 'ad-account-01' -SourceName 'ad-account-01'
```

Sets -SourceName on the Active Directory account named 'ad-account-01'.
