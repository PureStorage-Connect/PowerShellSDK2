# New-Pfa2Logout

## SYNOPSIS

(REST API 2.0+) Invalidate a session token.

## SYNTAX

```
New-Pfa2Logout [-Array <Rest2Api>] [-XAuthToken <String>] [-XRequestID <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Invalidate a session token.

## EXAMPLES

### Example 1
```powershell
New-Pfa2Logout -Array $FlashArray
```

Invalidates the x-auth-token of the current REST session.

### Example 2
```powershell
New-Pfa2Logout -Array $FlashArray -XAuthToken $AuthToken
```

Invalidates a specific x-auth-token, such as one returned earlier by New-Pfa2Login.
