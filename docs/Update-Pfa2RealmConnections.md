# Update-Pfa2RealmConnections

## SYNOPSIS

(REST API 2.43+) Modify a realm connection

## SYNTAX

```
Update-Pfa2RealmConnections [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-Id <List[String]>]
 [-LocalRealmIds <List[String]>]
 [-LocalRealmNames <List[String]>]
 [-RemoteRealmIds <List[String]>]
 [-RemoteRealmNames <List[String]>] [-Type <String>]
 [-ConnectionKey <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies an existing realm connection, for example to change the connection type or the replication addresses it uses.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2RealmConnections -Array $FlashArray -LocalRealmNames 'tenant-a'
```

Sets -LocalRealmNames on the realm connection.

### Example 2
```powershell
Update-Pfa2RealmConnections -Array $FlashArray -RemoteRealmNames 'tenant-b'
```

Sets -RemoteRealmNames on the realm connection.

### Example 3
```powershell
Update-Pfa2RealmConnections -Array $FlashArray -Type 'replication'
```

Sets -Type on the realm connection.
