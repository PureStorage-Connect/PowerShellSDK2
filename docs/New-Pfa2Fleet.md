# New-Pfa2Fleet

## SYNOPSIS

Create a fleet

## SYNTAX

```
New-Pfa2Fleet [-Array <Rest2Api>] [-XRequestID <String>] [-Name <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a fleet and adds the current array as its first member. Additional arrays can be added to the fleet with `New-Pfa2Fleet /fleets/members`.

## EXAMPLES

### Example 1
```powershell
New-Pfa2Fleet -Array $FlashArray -Name 'prod-fleet'
```

Creates a fleet with this array as its first member.

### Example 2
```powershell
New-Pfa2Fleet -Array $FlashArray
```

Creates a fleet and lets the array generate the name.
