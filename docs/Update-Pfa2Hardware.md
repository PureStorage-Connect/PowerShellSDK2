# Update-Pfa2Hardware

## SYNOPSIS

(REST API 2.2+) Modify visual identification

## SYNTAX

```
Update-Pfa2Hardware [-Array <Rest2Api>] [-XRequestID <String>] [-Name <String>] [-IdentifyEnabled <Boolean>]
 [-Index <Int32>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies the visual identification of a specified hardware component, and causing the ID LED to turn on or off.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2Hardware -Array $FlashArray -Name 'CT0.FC0' -IdentifyEnabled $true
```

Sets -IdentifyEnabled on the hardware component named 'CT0.FC0'.

### Example 2
```powershell
Update-Pfa2Hardware -Array $FlashArray -Name 'CT0.FC0' -Index 1
```

Sets -Index on the hardware component named 'CT0.FC0'.
