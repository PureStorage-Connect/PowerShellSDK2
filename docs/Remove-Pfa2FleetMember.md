# Remove-Pfa2FleetMember

## SYNOPSIS

Delete fleet members

## SYNTAX

```
Remove-Pfa2FleetMember [-Array <Rest2Api>] [-XRequestID <String>]
 [-MemberId <List[String]>]
 [-MemberName <List[String]>] [-Unreachable <Boolean>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes the specified array(s) from the fleet. Note that this will only succeed if the array(s) to be removed are not making use of any fleet resources.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2FleetMember -Array $FlashArray -MemberName 'array2' -Unreachable $true
```

Deletes the fleet member.

### Example 2
```powershell
Remove-Pfa2FleetMember -Array $FlashArray -MemberName 'array2'
```

Deletes the fleet member, also specifying -MemberName.

### Example 3
```powershell
Remove-Pfa2FleetMember -Array $FlashArray -Unreachable $true
```

Deletes the fleet member, also specifying -Unreachable.
