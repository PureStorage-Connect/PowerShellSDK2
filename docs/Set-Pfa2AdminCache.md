# Set-Pfa2AdminCache

## SYNOPSIS

(REST API 2.2+) Update or refresh entries in the administrator cache

## SYNTAX

```
Set-Pfa2AdminCache [-Array <Rest2Api>] [-XRequestID <String>] [-Name <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Updates entries in the cache for administrators who currently do not have a cache entry, otherwise refreshes the existing entry.

## EXAMPLES

### Example 1
```powershell
Set-Pfa2AdminCache -Array $FlashArray -Name 'jsmith'
```

Refreshes the cached directory-service entry for one administrator, so the next login re-reads their group membership and role from the directory.

### Example 2
```powershell
Get-Pfa2Admin -Array $FlashArray | ForEach-Object { Set-Pfa2AdminCache -Array $FlashArray -Name $_.Name }
```

Refreshes the cached entry for every administrator.
