# New-Pfa2HostHostGroup

## SYNOPSIS

(REST API 2.1+) Create a membership to a host group

## SYNTAX

```
New-Pfa2HostHostGroup [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-GroupName <List[String]>]
 [-MemberName <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a membership to a host group. Creating a membership to a host group automatically connects the host to all volumes associated with the group. Multiple hosts can be belong to a host group, but a host can only belong to one host group. Hosts can be added to host groups at any time. The `GroupName` and `MemberName` parameters are required and must be set together, and only one host group can be specified at a time.

## EXAMPLES

### Example 1
```powershell
New-Pfa2HostHostGroup -Array $FlashArray -GroupName $HostGroupName -MemberName $NewHost.Name
```

Add host $NewHost.Name to host group $HostGroupName.

### Example 2
```powershell
New-Pfa2HostHostGroup -Array $FlashArray -GroupName 'esx-cluster-01' -MemberName 'esx-host-01', 'esx-host-02'
```

Adds several hosts to host group 'esx-cluster-01' in a single call.
