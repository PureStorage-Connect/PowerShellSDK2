# Update-Pfa2DirectoryServiceRole

## SYNOPSIS

(REST API 2.2+) Modify group to management access policy mappings

## SYNTAX

```
Update-Pfa2DirectoryServiceRole [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] -Name <String>
 [-RoleName <List[String]>] [-Group <String>] [-GroupBase <String>]
 [-NewRoleName <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies properties of one or more group to management access policy mappings. Modifying management access policies is done at `/directory-services/roles/policies/management-access` instead.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2DirectoryServiceRole -Array $FlashArray -RoleNames $ArrayAdmin -Group $Group -GroupBase $GroupBase
```

Find directory service role by role name $ArrayAdmin and update with new values of Group and GroupBase.

### Example 2
```powershell
Update-Pfa2DirectoryServiceRole -Array $FlashArray -Name 'array_admin' -RoleName 'array_admin'
```

Sets -RoleName on the directory service role mapping named 'array_admin'.

### Example 3
```powershell
Update-Pfa2DirectoryServiceRole -Array $FlashArray -Name 'array_admin' -Group 'array_admin'
```

Sets -Group on the directory service role mapping named 'array_admin'.

### Example 4
```powershell
Update-Pfa2DirectoryServiceRole -Array $FlashArray -Name 'array_admin' -GroupBase 'array_admin'
```

Sets -GroupBase on the directory service role mapping named 'array_admin'.
