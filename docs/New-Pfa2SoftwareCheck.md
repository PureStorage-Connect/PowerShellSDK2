# New-Pfa2SoftwareCheck

## SYNOPSIS

(REST API 2.9+) Create a software check task

## SYNTAX

```
New-Pfa2SoftwareCheck [-Array <Rest2Api>] [-XRequestID <String>]
 [-SoftwareName <List[String]>]
 [-SoftwareVersion <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a software check task. If there are no previously queued or running software check tasks, the new task immediately starts. Otherwise, it is queued and starts once all previously queued or running software check tasks finish. To create a task, use a software name and version.

## EXAMPLES

### Example 1
```powershell
New-Pfa2SoftwareCheck -Array $FlashArray -SoftwareName 'purity//fa' -SoftwareVersion '6.8.4'
```

Creates a software upgrade check on the array.

### Example 2
```powershell
New-Pfa2SoftwareCheck -Array $FlashArray -SoftwareName 'purity//fa'
```

Creates a software upgrade check specifying only -SoftwareName.
