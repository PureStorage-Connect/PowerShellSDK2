# Update-Pfa2SyslogServer

## SYNOPSIS

(REST API 2.4+) Modify syslog server

## SYNTAX

```
Update-Pfa2SyslogServer [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-Name <String>]
 [-Service <List[String]>] [-Uri <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies the URI and services of a configured syslog server.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2SyslogServer -Array $FlashArray -Name 'syslog-01' -Service 'management'
```

Sets -Service on the syslog server named 'syslog-01'.

### Example 2
```powershell
Update-Pfa2SyslogServer -Array $FlashArray -Name 'syslog-01' -Uri 'kmip-server-01.example.com'
```

Sets -Uri on the syslog server named 'syslog-01'.
