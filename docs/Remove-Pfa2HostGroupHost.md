# Remove-Pfa2HostGroupHost

## SYNOPSIS

(REST API 2.1+) Delete a membership from a host group

## SYNTAX

```
Remove-Pfa2HostGroupHost [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-GroupName <List[String]>]
 [-MemberName <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes a membership from a host group. Removing a membership from a host group automatically disconnects the host from all volumes associated with the group. Hosts can be removed from host groups at any time. The `GroupName` and `MemberName` parameters are required and must be set together, and only one host group can be specified at a time.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2HostGroupHost -Array $FlashArray -GroupName $HostGroupName -MemberName $NewHost.Name
```

Remove host $NewHost.Name from host group $HostGroupName.

### Example 2
```powershell
Get-Pfa2HostGroupHost -Array $FlashArray -GroupName 'esx-cluster-01' | ForEach-Object { Remove-Pfa2HostGroupHost -Array $FlashArray -GroupName 'esx-cluster-01' -MemberName $_.Member.Name }
```

Removes every current member of host group 'esx-cluster-01'.
