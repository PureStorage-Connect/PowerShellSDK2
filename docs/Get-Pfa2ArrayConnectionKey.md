# Get-Pfa2ArrayConnectionKey

## SYNOPSIS

(REST API 2.4+) List connection key

## SYNTAX

```
Get-Pfa2ArrayConnectionKey [-Array <Rest2Api>] [-XRequestID <String>] [-Encrypted <Boolean>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Displays the connection key for the array.

## EXAMPLES

### Example 1
```powershell
Get-Pfa2ArrayConnectionKey -Array $FlashArray
```

Returns the connection key for this array. Supply it to New-Pfa2ArrayConnection on the peer array to pair the two for replication.

### Example 2
```powershell
(Get-Pfa2ArrayConnectionKey -Array $FlashArray -Encrypted $true).ConnectionKey
```

Returns an encrypted connection key, for pairing arrays over an untrusted network.
