# Remove-Pfa2Volume

## SYNOPSIS

(REST API 2.0+) Delete a volume

## SYNTAX

```
Remove-Pfa2Volume [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-Id <List[String]>] [-Name <String>] [-Eradicate] [-ApiVersion <String>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Deletes (eradicates) a volume that has been destroyed and is pending eradication. Eradicated volumes cannot be recovered. Volumes are destroyed using the `Update-Pfa2Volume` cmdlet. The `Ids` or `Name` parameter is required, but they cannot be set together.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2Volume -Array $FlashArray -Name 'db-vol-01' -Confirm:$false
```

Destroys the volume, putting it into the eradication pending state.

### Example 2
```powershell
Remove-Pfa2Volume -Array $FlashArray -Name 'db-vol-01' -Eradicate -Confirm:$false
```

Eradicates a volume that is already destroyed. This is permanent and cannot be undone. Only destroyed volumes can be eradicated.

### Example 3
```powershell
Remove-Pfa2Volume -Array $FlashArray -Name 'db-vol-01' -Eradicate -WhatIf
```

Shows what eradicating the volume would do without performing it.

### Example 4
```powershell
Get-Pfa2Volume -Array $FlashArray -Destroyed $true | Remove-Pfa2Volume -Array $FlashArray -Eradicate -Confirm:$false
```

Eradicates every volume that is already destroyed and pending eradication.
