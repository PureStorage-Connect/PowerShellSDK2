# New-Pfa2PolicyAutodir

## SYNOPSIS

Create auto managed directory policies

## SYNTAX

```
New-Pfa2PolicyAutodir [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-Name <String>]
 [-SourceId <List[String]>]
 [-SourceName <List[String]>] [-Enabled <Boolean>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates one or more auto managed directory policies. To copy a policy, set one of either `SourceName` or `SourceId`. Each policy can only have one entry. To create a policy from scratch, policy body is required.

## EXAMPLES

### Example 1
```powershell
New-Pfa2PolicyAutodir -Array $FlashArray -Name 'autodir-default'
```

Creates an auto-directory policy named 'autodir-default'.

### Example 2
```powershell
New-Pfa2PolicyAutodir -Array $FlashArray -Name 'autodir-default' -Enabled $true -SourceName 'autodir-default'
```

Creates an auto-directory policy and sets -Enabled and -SourceName in the same call.
