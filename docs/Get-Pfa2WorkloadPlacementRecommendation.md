# Get-Pfa2WorkloadPlacementRecommendation

## SYNOPSIS

List workload placement recommendations

## SYNTAX

```
Get-Pfa2WorkloadPlacementRecommendation [-Array <Rest2Api>] [-XRequestId <String>] [-AllowError <Boolean>]
 [-ContextName <List[String]>]
 [-Id <List[String]>] [-Limit <Int32>] [-Name <String>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Displays a list of placement recommendations for workloads.

## EXAMPLES

### Example 1
```powershell
Get-Pfa2WorkloadPlacementRecommendation -Array $FlashArray
```

Lists all workload placement recommendations on the array.

### Example 2
```powershell
Get-Pfa2WorkloadPlacementRecommendation -Array $FlashArray -Name 'sql-prod-workload'
```

Returns the workload placement recommendation named 'sql-prod-workload'.
