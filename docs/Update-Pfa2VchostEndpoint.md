# Update-Pfa2VchostEndpoint

## SYNOPSIS

Modify a vchost endpoint

## SYNTAX

```
Update-Pfa2VchostEndpoint [-Array <Rest2Api>] [-XRequestID <String>]
 [-Endpoint <List[String]>]
 [-Id <List[String]>]
 [-VchostId <List[String]>]
 [-VchostName <List[String]>]
 [-CertificatesName <List[String]>]
 [-CertificatesResourceType <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies an existing vchost endpoint. The `Id` query parameter alone, or the `Endpoint` query parameter together with one of `VchostName` or `VchostId`, is required.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2VchostEndpoint -Array $FlashArray -Endpoint 'vchost-01-endpoint'
```

Sets -Endpoint on the vchost endpoint.

### Example 2
```powershell
Update-Pfa2VchostEndpoint -Array $FlashArray -CertificatesName 'vchost-01-cert'
```

Sets -CertificatesName on the vchost endpoint.

### Example 3
```powershell
Update-Pfa2VchostEndpoint -Array $FlashArray -CertificatesResourceType 'vchost-01-endpoint'
```

Sets -CertificatesResourceType on the vchost endpoint.
