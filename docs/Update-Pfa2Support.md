# Update-Pfa2Support

## SYNOPSIS

(REST API 2.2+) Create connection path

## SYNTAX

```
Update-Pfa2Support [-Array <Rest2Api>] [-XRequestID <String>] [-PhonehomeEnabled <Boolean>]
 [-PhonehomeExcludes <List[String]>] [-Proxy <String>]
 [-RemoteAssistActive <Boolean>] [-RemoteAssistDuration <Int64>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a connection path from the array to another array.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2Support -array $FlashArray -PhonehomeEnabled $false -Proxy $proxy -RemoteAssistActive $false
```

Update a connection path by setting values of Proxy, PhonehomeEnabled, and RemoteAssistActive.

### Example 2
```powershell
Update-Pfa2Support -Array $FlashArray -PhonehomeEnabled $true
```

Sets -PhonehomeEnabled on the remote support configuration.

### Example 3
```powershell
Update-Pfa2Support -Array $FlashArray -PhonehomeExcludes 'support'
```

Sets -PhonehomeExcludes on the remote support configuration.

### Example 4
```powershell
Update-Pfa2Support -Array $FlashArray -Proxy 'support'
```

Sets -Proxy on the remote support configuration.
