# New-Pfa2DirectorySnapshot

## SYNOPSIS

(REST API 2.3+) Create directory snapshot

## SYNTAX

```
New-Pfa2DirectorySnapshot [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-SourceId <List[String]>]
 [-SourceName <List[String]>] [-ClientName <String>] [-KeepFor <Int64>]
 [-Suffix <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a snapshot of the contents of a directory. The `SourceId` or `SourceName` parameter is required, but they cannot be set together.

## EXAMPLES

### Example 1
```powershell
New-Pfa2DirectorySnapshot -Array $FlashArray -SourceName 'fs-prod-01:home'
```

Takes a directory snapshot of 'fs-prod-01:home' using an array-generated suffix.

### Example 2
```powershell
New-Pfa2DirectorySnapshot -Array $FlashArray -SourceName 'fs-prod-01:home' -Suffix 'daily'
```

Takes a directory snapshot of 'fs-prod-01:home' with the suffix `daily`, producing 'fs-prod-01:home.daily'.

### Example 3
```powershell
New-Pfa2DirectorySnapshot -Array $FlashArray -SourceName 'fs-prod-01:home', 'fs-prod-02:home' -Suffix 'daily'
```

Takes a consistent directory snapshot of several sources at once.
