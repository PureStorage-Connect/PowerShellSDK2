# New-Pfa2Subnet

## SYNOPSIS

(REST API 2.2+) Create subnet

## SYNTAX

```
New-Pfa2Subnet [-Array <Rest2Api>] [-XRequestID <String>] -Name <String> [-Enabled <Boolean>]
 [-Gateway <String>] [-Mtu <Int32>] [-Prefix <String>] [-Vlan <Int32>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a subnet with the specified parameters.

## EXAMPLES

### Example 1
```powershell
New-Pfa2Subnet -Array $FlashArray -Name $Name -Enabled $true -Gateway $Geteway -Mtu $Mtu -Prefix $Prefix -Vlan $Vlan
```

Create a new subnet with parameters of name, enabled, gateway, mtu, prefix, and vlan.

### Example 2
```powershell
New-Pfa2Subnet -Array $FlashArray -Name 'replication-subnet'
```

Creates a subnet with only the required parameters supplied.

### Example 3
```powershell
New-Pfa2Subnet -Array $FlashArray -Name 'replication-subnet' -Enabled $true -Gateway '10.0.1.1'
```

Creates a subnet and sets -Enabled and -Gateway in the same call.
