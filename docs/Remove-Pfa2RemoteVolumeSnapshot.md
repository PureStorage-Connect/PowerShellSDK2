# Remove-Pfa2RemoteVolumeSnapshot

## SYNOPSIS

(REST API 2.4+) Delete a remote volume snapshot

## SYNTAX

```
Remove-Pfa2RemoteVolumeSnapshot [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-Name <String>] [-On <String>]
 [-ReplicationSnapshot <Boolean>] [-Eradicate] [-ApiVersion <String>]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Deletes a remote volume snapshot that has been destroyed and is pending eradication. Eradicated remote volume snapshots cannot be recovered. Remote volume snapshots are destroyed through the `Update-Pfa2RemoteVolumeSnapshot` method. The `Name` parameter represents the name of the volume snapshot. The `On` parameter represents the name of the offload target. The `Name` and `On` parameters are required and must be used together.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2RemoteVolumeSnapshot -Array $FlashArray -Name 'array2:db-vol-01.daily' -Confirm:$false
```

Deletes the remote volume snapshot named 'array2:db-vol-01.daily'.

### Example 2
```powershell
Remove-Pfa2RemoteVolumeSnapshot -Array $FlashArray -Name 'array2:db-vol-01.daily' -Eradicate -Confirm:$false
```

Permanently eradicates the destroyed remote volume snapshot named 'array2:db-vol-01.daily'. This bypasses the eradication pending period and cannot be undone.

### Example 3
```powershell
Get-Pfa2RemoteVolumeSnapshot -Array $FlashArray -Destroyed $true | Remove-Pfa2RemoteVolumeSnapshot -Array $FlashArray -Eradicate -Confirm:$false
```

Eradicates every remote volume snapshot that is already destroyed and pending eradication.
