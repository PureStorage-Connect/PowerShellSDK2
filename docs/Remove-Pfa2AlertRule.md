# Remove-Pfa2AlertRule

## SYNOPSIS

Delete a custom alert rule

## SYNTAX

```
Remove-Pfa2AlertRule [-Array <Rest2Api>] [-XRequestID <String>] -Code <Int32> -Parameter <String>
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes a custom alert rule.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2AlertRule -Array $FlashArray -Code 42 -Parameter '--force'
```

Deletes an alert rule, identified by its alert code and rule parameter.

### Example 2
```powershell
Get-Pfa2AlertRule -Array $FlashArray | Format-Table Code, Parameter, Name -AutoSize
```

Lists the alert rules with the code and parameter values needed to delete one.
