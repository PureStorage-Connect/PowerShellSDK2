# New-Pfa2DirectoryPolicyAutodir

## SYNOPSIS

Create a membership between a directory with one or more auto managed directory policies

## SYNTAX

```
New-Pfa2DirectoryPolicyAutodir [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-MemberId <List[String]>]
 [-MemberName <List[String]>]
 [-PolicyId <List[String]>]
 [-PolicyName <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a membership between a directory with one or more auto managed directory policies. The `MemberId` or `MemberName` parameter is required, but they cannot be set together.

## EXAMPLES

### Example 1
```powershell
New-Pfa2DirectoryPolicyAutodir -Array $FlashArray -PolicyName 'policy-autodir-01' -MemberName 'autodir-default'
```

Adds auto-directory policy 'autodir-default' to managed directory 'fs-prod-01:home'.

### Example 2
```powershell
New-Pfa2DirectoryPolicyAutodir -Array $FlashArray -PolicyName 'policy-autodir-01' -MemberName 'autodir-default', 'autodir-default-02'
```

Adds several auto-directory policies to managed directory 'fs-prod-01:home' in a single call.
