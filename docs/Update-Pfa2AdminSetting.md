# Update-Pfa2AdminSetting

## SYNOPSIS

(REST API 2.2+) Modify administrator settings

## SYNTAX

```
Update-Pfa2AdminSetting [-Array <Rest2Api>] [-XRequestID <String>] [-LockoutDuration <Int64>]
 [-MaxLoginAttempts <Int32>] [-MinPasswordLength <Int32>] [-SingleSignOnEnabled <Boolean>]
 [-RequiredAuthenticationMethodsSsh <List[String]>]
 [-RequiredAuthenticationMethodsWebUi <List[String]>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies the global administrator settings for the array.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2AdminSetting -Array $FlashArray -LockoutDuration 1000 -MaxLoginAttempts 3 -MinPasswordLength 10
```

Update global array admin setting. Lockout duration to 1000 secs, maximum login attempts to 3 and minimum password length to 10.

### Example 2
```powershell
Update-Pfa2AdminSetting -Array $FlashArray -MaxLoginAttempts 2
```

Update global array admin setting. Maximum login attempts to only 2.

### Example 3
```powershell
Update-Pfa2AdminSetting -Array $FlashArray -LockoutDuration 2000
```

Update global array admin setting. Lockout duration to 2000 seconds.

### Example 4
```powershell
Update-Pfa2AdminSetting -Array $FlashArray -MinPasswordLength 10
```

Sets -MinPasswordLength on the global administrator setting.
