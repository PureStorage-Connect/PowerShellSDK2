# Remove-Pfa2ProtectionGroupSnapshot

## SYNOPSIS

(REST API 2.1+) Delete a protection group snapshot

## SYNTAX

```
Remove-Pfa2ProtectionGroupSnapshot [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-Id <List[String]>] [-Name <String>] [-Eradicate] [-ApiVersion <String>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Deletes a protection group snapshot that has been destroyed and is pending eradication. Eradicating a protection group snapshot eradicates all of its protection group snapshots and cannot be recovered. Protection group snapshots are destroyed through the `Update-Pfa2ProtectionGroupSnapshot` method. The `Name` or `Id` parameter is required, but they cannot be set together.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2ProtectionGroupSnapshot -Array $FlashArray -Name $SnapshotName
```

Eradicate a protection group snapshot named $SnapshotName.

### Example 2
```powershell
Remove-Pfa2ProtectionGroupSnapshot -Array $FlashArray -Name 'db-daily-pg.hourly' -Confirm:$false
```

Deletes the protection group snapshot named 'db-daily-pg.hourly'.

### Example 3
```powershell
Remove-Pfa2ProtectionGroupSnapshot -Array $FlashArray -Name 'db-daily-pg.hourly' -Eradicate -Confirm:$false
```

Permanently eradicates the destroyed protection group snapshot named 'db-daily-pg.hourly'. This bypasses the eradication pending period and cannot be undone.

### Example 4
```powershell
Get-Pfa2ProtectionGroupSnapshot -Array $FlashArray -Destroyed $true | Remove-Pfa2ProtectionGroupSnapshot -Array $FlashArray -Eradicate -Confirm:$false
```

Eradicates every protection group snapshot that is already destroyed and pending eradication.
