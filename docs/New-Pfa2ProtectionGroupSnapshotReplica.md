# New-Pfa2ProtectionGroupSnapshotReplica

## SYNOPSIS

Create an action to send protection group snapshots

## SYNTAX

```
New-Pfa2ProtectionGroupSnapshotReplica [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-ConvertSourceToBaseline <Boolean>]
 [-Id <List[String]>] [-Name <String>]
 [-On <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates an action to send protection group snapshots to protection pgroup targets. When the `On` option is used, only specified targets will recieve the protection group snapshots.

## EXAMPLES

### Example 1
```powershell
New-Pfa2ProtectionGroupSnapshotReplica -Array $FlashArray -Name 'db-daily-pg.hourly'
```

Creates a protection group snapshot replica named 'db-daily-pg.hourly'.

### Example 2
```powershell
New-Pfa2ProtectionGroupSnapshotReplica -Array $FlashArray -Name 'db-daily-pg.hourly' -ConvertSourceToBaseline $true -On 'nfs-offload'
```

Creates a protection group snapshot replica and sets -ConvertSourceToBaseline and -On in the same call.
