# Invoke-Pfa2RestCommand

## SYNOPSIS

Execute REST request on the FlashArray

## SYNTAX

```
Invoke-Pfa2RestCommand [-Array <Rest2Api>] -Method <Method> -RelativeUri <String> [-Body <String>]
 [-XRequestId <String>] [-UseHttp] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION

Execute REST request on the FlashArray

## EXAMPLES

### Example 1
```powershell
Invoke-Pfa2RestCommand -Array $FlashArray -Method 'GET' -RelativeUri 'volumes?limit=5'
```

Calls a REST endpoint directly. -RelativeUri is appended to the array base URI, so this maps to /api/<version>/volumes?limit=5.

### Example 2
```powershell
Invoke-Pfa2RestCommand -Array $FlashArray -Method 'POST' -RelativeUri 'volumes?names=db-vol-01' -Body '{ "provisioned": 1099511627776 }'
```

Creates a 1 TB volume by posting a raw JSON body. Use this to reach REST features that do not yet have a dedicated cmdlet.

### Example 3
```powershell
Invoke-Pfa2RestCommand -Array $FlashArray -Method 'DELETE' -RelativeUri 'volumes?names=db-vol-01' -Confirm:$false
```

Sends a DELETE request without prompting for confirmation.
