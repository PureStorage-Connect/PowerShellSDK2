# New-Pfa2SoftwareBundle

## SYNOPSIS

(REST API 2.5+) Create software-bundle

## SYNTAX

```
New-Pfa2SoftwareBundle [-Array <Rest2Api>] [-XRequestID <String>] [-Source <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates and initiates a software bundle download.

## EXAMPLES

### Example 1
```powershell
New-Pfa2SoftwareBundle -Array $FlashArray -Source '/tmp/purity-6.8.4.bundle'
```

Uploads a software bundle to the array so it becomes available to install.

### Example 2
```powershell
Get-Pfa2SoftwareBundle -Array $FlashArray | Format-Table Name, Version, Status -AutoSize
```

Lists the software bundles already on the array.
