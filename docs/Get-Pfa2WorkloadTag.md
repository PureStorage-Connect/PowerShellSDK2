# Get-Pfa2WorkloadTag

## SYNOPSIS

List tags

## SYNTAX

```
Get-Pfa2WorkloadTag [-Array <Rest2Api>] [-XRequestID <String>] [-AllowError <Boolean>]
 [-ContextName <List[String]>]
 [-Namespace <List[String]>]
 [-ResourceId <List[String]>]
 [-ResourceName <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Displays the list of tags.

## EXAMPLES

### Example 1
```powershell
Get-Pfa2WorkloadTag -Array $FlashArray -ResourceName 'sql-prod-workload'
```

Lists the tags applied to a workload.

### Example 2
```powershell
Get-Pfa2WorkloadTag -Array $FlashArray -ResourceName 'sql-prod-workload' -Namespace 'default'
```

Lists only the tags in the default namespace.

### Example 3
```powershell
Get-Pfa2WorkloadTag -Array $FlashArray
```

Lists all workload tags on the array.
