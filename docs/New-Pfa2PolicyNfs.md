# New-Pfa2PolicyNfs

## SYNOPSIS

(REST API 2.3+) Create NFS policies

## SYNTAX

```
New-Pfa2PolicyNfs [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-Name <String>]
 [-SourceId <List[String]>]
 [-SourceName <List[String]>] [-Enabled <Boolean>]
 [-UserMappingEnabled <Boolean>] [-PolicyMappingMapping <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates one or more NFS policies or copies an existing policy. To copy a policy, the `SourceName` or `SourceId` parameter is required, but they cannot be set together. To create a policy, policy body is required.

## EXAMPLES

### Example 1
```powershell
New-Pfa2PolicyNfs -Array $FlashArray -Name 'nfs-default'
```

Creates an NFS policy named 'nfs-default'.

### Example 2
```powershell
New-Pfa2PolicyNfs -Array $FlashArray -Name 'nfs-default' -Enabled $true -SourceName 'nfs-default'
```

Creates an NFS policy and sets -Enabled and -SourceName in the same call.
