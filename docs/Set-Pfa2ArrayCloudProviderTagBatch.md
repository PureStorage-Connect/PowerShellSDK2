# Set-Pfa2ArrayCloudProviderTagBatch

## SYNOPSIS

(REST API 2.6+) Update user tags on the cloud.

## SYNTAX

```
Set-Pfa2ArrayCloudProviderTagBatch [-Array <Rest2Api>] [-XRequestID <String>]
 [-TagKey <List[String]>]
 [-TagValue <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Updates users tags to deployed cloud resources of a CBS array.

## EXAMPLES

### Example 1
```powershell
Set-Pfa2ArrayCloudProviderTagBatch -Array $FlashArray -TagKey 'environment' -TagValue 'production'
```

Applies the tag `environment=production` to the array.

### Example 2
```powershell
Set-Pfa2ArrayCloudProviderTagBatch -Array $FlashArray -TagKey 'environment', 'owner' -TagValue 'production', 'storage-ops'
```

Applies two tags to the array in one call. -TagKey and -TagValue are positional lists, matched pairwise.
