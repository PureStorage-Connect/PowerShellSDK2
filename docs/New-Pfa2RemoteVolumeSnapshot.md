# New-Pfa2RemoteVolumeSnapshot

## SYNOPSIS

(REST API 2.4+) Create a volume snapshot on a connected remote target or offload target

## SYNTAX

```
New-Pfa2RemoteVolumeSnapshot [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-On <String>]
 [-SourceId <List[String]>]
 [-SourceName <List[String]>] [-Suffix <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a volume snapshot on the specified connected remote target or offload target.

## EXAMPLES

### Example 1
```powershell
New-Pfa2RemoteVolumeSnapshot -Array $FlashArray -SourceName 'array2:db-vol-01.daily'
```

Takes a remote volume snapshot of 'array2:db-vol-01.daily' using an array-generated suffix.

### Example 2
```powershell
New-Pfa2RemoteVolumeSnapshot -Array $FlashArray -SourceName 'array2:db-vol-01.daily' -Suffix 'daily'
```

Takes a remote volume snapshot of 'array2:db-vol-01.daily' with the suffix `daily`, producing 'array2:db-vol-01.daily.daily'.

### Example 3
```powershell
New-Pfa2RemoteVolumeSnapshot -Array $FlashArray -SourceName 'array2:db-vol-01.daily', 'array2:db-vol-02.daily' -Suffix 'daily'
```

Takes a consistent remote volume snapshot of several sources at once.
