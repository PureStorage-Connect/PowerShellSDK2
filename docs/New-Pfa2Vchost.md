# New-Pfa2Vchost

## SYNOPSIS

Create a vchost

## SYNTAX

```
New-Pfa2Vchost [-Array <Rest2Api>] [-XRequestID <String>] [-Name <String>] [-Vcuuid <String>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a vchost. The `Name` query parameter is required.

## EXAMPLES

### Example 1
```powershell
New-Pfa2Vchost -Array $FlashArray -Name 'vchost-01'
```

Creates a virtual host (vchost) named 'vchost-01'.

### Example 2
```powershell
New-Pfa2Vchost -Array $FlashArray -Name 'vchost-01' -Vcuuid 'vchost-01'
```

Creates a virtual host (vchost) and sets -Vcuuid in the same call.
