# Update-Pfa2SyslogServerSetting

## SYNOPSIS

(REST API 2.4+) Modify syslog settings

## SYNTAX

```
Update-Pfa2SyslogServerSetting [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-CaCertificate <String>]
 [-LoggingSeverity <String>] [-TlsAuditEnabled <Boolean>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies syslog settings. Values include `continuation_token`, `items`, `more_items_remaining`, and `TotalItemCount`.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2SyslogServerSetting -Array $FlashArray -CaCertificate $CaCertificatePem
```

Sets -CaCertificate on the syslog server setting.

### Example 2
```powershell
Update-Pfa2SyslogServerSetting -Array $FlashArray -LoggingSeverity 'syslog-01'
```

Sets -LoggingSeverity on the syslog server setting.

### Example 3
```powershell
Update-Pfa2SyslogServerSetting -Array $FlashArray -TlsAuditEnabled $true
```

Sets -TlsAuditEnabled on the syslog server setting.
