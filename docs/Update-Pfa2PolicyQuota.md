# Update-Pfa2PolicyQuota

## SYNOPSIS

(REST API 2.7+) Modify quota policies

## SYNTAX

```
Update-Pfa2PolicyQuota [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-Id <List[String]>] [-IgnoreUsage <Boolean>] [-Name <String>]
 [-PolicyName <String>] [-Enabled <Boolean>] [-ApiVersion <String>]
 [<CommonParameters>]
```

## DESCRIPTION

Modifies one or more quota policies. To enable a policy, set `Enabled=$True`. To disable a policy, set `Enabled=$False`. To rename a policy, set `PolicyName` to the new name. The `Id` or `Name` parameter is required, but they cannot be set together.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2PolicyQuota -Array $FlashArray -Name 'quota-10t' -Enabled $true
```

Sets -Enabled on the quota policy named 'quota-10t'.

### Example 2
```powershell
Update-Pfa2PolicyQuota -Array $FlashArray -Name 'quota-10t' -PolicyName 'quota-10t'
```

Sets -PolicyName on the quota policy named 'quota-10t'.

### Example 3
```powershell
Update-Pfa2PolicyQuota -Array $FlashArray -Name 'quota-10t' -IgnoreUsage $true
```

Sets -IgnoreUsage on the quota policy named 'quota-10t'.
