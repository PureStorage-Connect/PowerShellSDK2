# Update-Pfa2SmiS

## SYNOPSIS

(REST API 2.2+) Modify SLP and SMI-S

## SYNTAX

```
Update-Pfa2SmiS [-Array <Rest2Api>] [-XRequestID <String>] [-SlpEnabled <Boolean>]
 [-WbemHttpsEnabled <Boolean>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies the Service Location Protocol (SLP) and the SMI-S provider, enabling or disabling them.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2SmiS -array $FlashArray -WbemHttpsEnabled $false -SlpEnabled $false
```

Update SMI-S by disabling WbemHttps and Slp.

### Example 2
```powershell
Update-Pfa2SmiS -Array $FlashArray -SlpEnabled $true
```

Sets -SlpEnabled on the smi s.

### Example 3
```powershell
Update-Pfa2SmiS -Array $FlashArray -WbemHttpsEnabled $true
```

Sets -WbemHttpsEnabled on the smi s.
