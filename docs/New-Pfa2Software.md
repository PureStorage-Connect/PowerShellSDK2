# New-Pfa2Software

## SYNOPSIS

(REST API 2.9+) Create a software package

## SYNTAX

```
New-Pfa2Software [-Array <Rest2Api>] [-XRequestID <String>] [-SoftwareName <String>] [-Version <String>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a software package download.

## EXAMPLES

### Example 1
```powershell
New-Pfa2Software -Array $FlashArray -SoftwareName 'purity//fa' -Version '6.8.4'
```

Creates a software package on the array.

### Example 2
```powershell
New-Pfa2Software -Array $FlashArray -SoftwareName 'purity//fa'
```

Creates a software package specifying only -SoftwareName.
