# Get-Pfa2Certificate

## SYNOPSIS

(REST API 2.4+) List certificate attributes

## SYNTAX

```
Get-Pfa2Certificate [-Array <Rest2Api>] [-XRequestID <String>] [-Filter <String>]
 [-Id <List[String]>] [-Limit <Int32>] [-Name <String>] [-Offset <Int32>]
 [-Sort <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Displays certificate attributes.

## EXAMPLES

### Example 1
```powershell
Get-Pfa2Certificate -Array $FlashArray
```

Lists all certificates on the array.

### Example 2
```powershell
Get-Pfa2Certificate -Array $FlashArray -Name 'management'
```

Returns the certificate named 'management'.

### Example 3
```powershell
Get-Pfa2Certificate -Array $FlashArray -Filter "name='management*'"
```

Returns only the certificates matching a server-side filter expression. For the filter syntax, run `Help about_Pfa2Filtering`.

### Example 4
```powershell
Get-Pfa2Certificate -Array $FlashArray -Limit 25 -Sort 'name-'
```

Returns the first 25 certificates sorted by name in descending order. Append `-` to a field name to reverse the sort.
