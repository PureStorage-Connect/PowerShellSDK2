# New-Pfa2SoftwarePatch

## SYNOPSIS

Create a software patch

## SYNTAX

```
New-Pfa2SoftwarePatch [-Array <Rest2Api>] [-XRequestID <String>] [-AllowHaReduction <Boolean>] -Name <String>
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates software patch download and installation.

## EXAMPLES

### Example 1
```powershell
New-Pfa2SoftwarePatch -Array $FlashArray -Name 'purity-6.8.4-patch'
```

Creates a software patch with only the required parameters supplied.

### Example 2
```powershell
New-Pfa2SoftwarePatch -Array $FlashArray -Name 'purity-6.8.4-patch' -AllowHaReduction $true
```

Creates a software patch and sets -AllowHaReduction in the same call.
