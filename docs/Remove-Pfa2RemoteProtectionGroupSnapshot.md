# Remove-Pfa2RemoteProtectionGroupSnapshot

## SYNOPSIS

(REST API 2.1+) Delete a remote protection group snapshot

## SYNTAX

```
Remove-Pfa2RemoteProtectionGroupSnapshot [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-Id <List[String]>] [-Name <String>] [-On <String>] [-Eradicate]
 [-ApiVersion <String>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Deletes a remote protection group snapshot that has been destroyed and is pending eradication. Eradicated remote protection group snapshots cannot be recovered. Remote protection group snapshots are destroyed using the `Update-Pfa2RemoteProtectionGroupSnapshot` method. The `Name` parameter represents the name of the protection group snapshot. The `On` parameter represents the name of the offload target. The `Name` and `On` parameters are required and must be used together.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2RemoteProtectionGroupSnapshot -Array $testarray -Name $PeergroupSnapshot -On $NFSTargetName
```

Eradicate a remote protection group snapshot named $PeergroupSnapshot on remote target $NFSTargetName.

### Example 2
```powershell
Remove-Pfa2RemoteProtectionGroupSnapshot -Array $FlashArray -Name 'array2:db-daily-pg.hourly' -Confirm:$false
```

Deletes the remote protection group snapshot named 'array2:db-daily-pg.hourly'.

### Example 3
```powershell
Remove-Pfa2RemoteProtectionGroupSnapshot -Array $FlashArray -Name 'array2:db-daily-pg.hourly' -Eradicate -Confirm:$false
```

Permanently eradicates the destroyed remote protection group snapshot named 'array2:db-daily-pg.hourly'. This bypasses the eradication pending period and cannot be undone.

### Example 4
```powershell
Get-Pfa2RemoteProtectionGroupSnapshot -Array $FlashArray -Destroyed $true | Remove-Pfa2RemoteProtectionGroupSnapshot -Array $FlashArray -Eradicate -Confirm:$false
```

Eradicates every remote protection group snapshot that is already destroyed and pending eradication.
