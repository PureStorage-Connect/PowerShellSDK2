# Get-Pfa2AlertRule

## SYNOPSIS

List custom alert rules

## SYNTAX

```
Get-Pfa2AlertRule [-Array <Rest2Api>] [-XRequestID <String>] [-AllowError <Boolean>] [-Code <Int32>]
 [-ContextName <List[String]>] [-Filter <String>] [-Limit <Int32>]
 [-Offset <Int32>] [-Sort <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Displays a list of custom alert rules.

## EXAMPLES

### Example 1
```powershell
Get-Pfa2AlertRule -Array $FlashArray
```

Lists all alert rules on the array.

### Example 2
```powershell
Get-Pfa2AlertRule -Array $FlashArray -Filter "name='capacity*'"
```

Returns only the alert rules matching a server-side filter expression. For the filter syntax, run `Help about_Pfa2Filtering`.

### Example 3
```powershell
Get-Pfa2AlertRule -Array $FlashArray -Limit 25 -Sort 'name-'
```

Returns the first 25 alert rules sorted by name in descending order. Append `-` to a field name to reverse the sort.
