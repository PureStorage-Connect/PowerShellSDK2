# Update-Pfa2Certificate

## SYNOPSIS

(REST API 2.4+) Modify certificates

## SYNTAX

```
Update-Pfa2Certificate [-Array <Rest2Api>] [-XRequestID <String>] [-GenerateNewKey <Boolean>]
 [-Id <List[String]>] [-Name <String>] [-Certificate <String>]
 [-CommonName <String>] [-Country <String>] [-Email <String>] [-IntermediateCertificate <String>]
 [-KeyAlgorithm <String>] [-KeySize <Int32>] [-Locality <String>] [-Organization <String>]
 [-OrganizationalUnit <String>] [-State <String>]
 [-SubjectAlternativeNames <List[String]>] [-Days <Int32>] [-Key <String>]
 [-Passphrase <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies certificate attributes. Modifying self-signed certificate attributes replaces the existing certificate with a new one, generated by Purity//FA, using the specified attributes.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2Certificate -Array $FlashArray -Name 'management' -GenerateNewKey $true
```

Sets -GenerateNewKey on the certificate named 'management'.

### Example 2
```powershell
Update-Pfa2Certificate -Array $FlashArray -Name 'management' -Certificate $CertificatePem
```

Sets -Certificate on the certificate named 'management'.

### Example 3
```powershell
Update-Pfa2Certificate -Array $FlashArray -Name 'management' -CommonName 'flasharray-01.example.com'
```

Sets -CommonName on the certificate named 'management'.
