# Update-Pfa2Vchost

## SYNOPSIS

Modify a vchost

## SYNTAX

```
Update-Pfa2Vchost [-Array <Rest2Api>] [-XRequestID <String>]
 [-Id <List[String]>] [-Name <String>] [-VchostName <String>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies an existing vchost. The `Name` or `Id` query parameter is required.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2Vchost -Array $FlashArray -Name 'vchost-01' -VchostName 'vchost-01-renamed'
```

Renames a vchost.

### Example 2
```powershell
Get-Pfa2Vchost -Array $FlashArray | Format-Table Name, Id -AutoSize
```

Lists the vchosts defined on the array.
