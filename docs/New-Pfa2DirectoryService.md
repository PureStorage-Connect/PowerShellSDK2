# New-Pfa2DirectoryService

## SYNOPSIS

Create directory services configuration

## SYNTAX

```
New-Pfa2DirectoryService [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] -Name <String> [-BaseDn <String>]
 [-BindPassword <String>] [-BindUser <String>] [-Enabled <Boolean>]
 [-Uri <List[String]>]
 [-SourceId <List[String]>]
 [-SourceName <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates directory services configuration. All directory services configuration created using this resource will have `services` set to `data`.

## EXAMPLES

### Example 1
```powershell
New-Pfa2DirectoryService -Array $FlashArray -Name 'management'
```

Creates a directory service configuration with only the required parameters supplied.

### Example 2
```powershell
New-Pfa2DirectoryService -Array $FlashArray -Name 'management' -Enabled $true -BaseDn 'management'
```

Creates a directory service configuration and sets -Enabled and -BaseDn in the same call.
