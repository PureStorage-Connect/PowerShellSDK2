# New-Pfa2DirectoryServiceLocalGroup

## SYNOPSIS

Create local group

## SYNTAX

```
New-Pfa2DirectoryServiceLocalGroup [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-LocalDirectoryServiceId <List[String]>]
 [-LocalDirectoryServiceName <List[String]>] -Name <String>
 [-Email <String>] [-Gid <Int32>] [-ApiVersion <String>]
 [<CommonParameters>]
```

## DESCRIPTION

Creates a local group.

## EXAMPLES

### Example 1
```powershell
New-Pfa2DirectoryServiceLocalGroup -Array $FlashArray -Name 'storage-admins'
```

Creates a local directory group with only the required parameters supplied.

### Example 2
```powershell
New-Pfa2DirectoryServiceLocalGroup -Array $FlashArray -Name 'storage-admins' -LocalDirectoryServiceName 'directory-service-01' -Email 'storage-ops@example.com'
```

Creates a local directory group and sets -LocalDirectoryServiceName and -Email in the same call.
