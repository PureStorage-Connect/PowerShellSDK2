# Update-Pfa2Drive

## SYNOPSIS

(REST API 2.4+) Modify flash and NVRAM modules

## SYNTAX

```
Update-Pfa2Drive [-Array <Rest2Api>] [-XRequestID <String>] [-Admit <Boolean>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies flash and NVRAM modules that have been added or connected but not yet admitted to the array.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2Drive -Array $FlashArray -Admit $true
```

Admits every drive that is waiting to be admitted, so Purity starts using the replacement capacity. The cmdlet acts on the whole array; there is no per-drive parameter.

### Example 2
```powershell
Get-Pfa2Drive -Array $FlashArray -Filter "status='unadmitted'" | Format-Table Name, Type, Capacity -AutoSize
```

Lists the drives currently waiting to be admitted, to check before admitting them.
