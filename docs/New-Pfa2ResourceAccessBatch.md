# New-Pfa2ResourceAccessBatch

## SYNOPSIS

Create a resource access configuration

## SYNTAX

```
New-Pfa2ResourceAccessBatch [-Array <Rest2Api>] [-XRequestID <String>]
 [-ItemsScopeId <List[String]>]
 [-ItemsScopeName <List[String]>]
 [-ItemsScopeResourceType <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates resource access objects.

## EXAMPLES

### Example 1
```powershell
New-Pfa2ResourceAccessBatch -Array $FlashArray -ItemsScopeName 'items-scope-01' -ItemsScopeResourceType 'volumes'
```

Creates a resource access grant on the array.

### Example 2
```powershell
New-Pfa2ResourceAccessBatch -Array $FlashArray -ItemsScopeName 'items-scope-01'
```

Creates a resource access grant specifying only -ItemsScopeName.
