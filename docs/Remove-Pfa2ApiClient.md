# Remove-Pfa2ApiClient

## SYNOPSIS

(REST API 2.1+) Delete an API client

## SYNTAX

```
Remove-Pfa2ApiClient [-Array <Rest2Api>] [-XRequestID <String>]
 [-Id <List[String]>] [-Name <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes an API client. The `Id` or `Name` parameter is required, but they cannot be set together.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2ApiClient -Array $FlashArray -Name $ClientName
```

Remove API client with name $ClientName.

### Example 2
```powershell
Get-Pfa2ApiClient -Array $FlashArray -Filter "name='automation*'" | Remove-Pfa2ApiClient -Array $FlashArray
```

Deletes every API client returned by the filter by piping the results into Remove-Pfa2ApiClient.
