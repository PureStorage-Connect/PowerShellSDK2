# New-Pfa2NetworkInterface

## SYNOPSIS

(REST API 2.4+) Create network interface

## SYNTAX

```
New-Pfa2NetworkInterface [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-Name <String>]
 [-Service <List[String]>]
 [-AttachedServerId <List[String]>]
 [-AttachedServerName <List[String]>] [-EthAddress <String>]
 [-EthSubtype <String>] [-EthSubinterfaceName <List[String]>]
 [-EthSubnetName <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a network interface on a controller on the array.

## EXAMPLES

### Example 1
```powershell
New-Pfa2NetworkInterface -Array $FlashArray -Name 'ct0.eth4'
```

Creates a network interface named 'ct0.eth4'.

### Example 2
```powershell
New-Pfa2NetworkInterface -Array $FlashArray -Name 'ct0.eth4' -Service 'management' -AttachedServerName 'attached-server-01'
```

Creates a network interface and sets -Service and -AttachedServerName in the same call.
