# New-Pfa2VchostEndpoint

## SYNOPSIS

Create a vchost endpoint

## SYNTAX

```
New-Pfa2VchostEndpoint [-Array <Rest2Api>] [-XRequestID <String>]
 [-VchostId <List[String]>]
 [-VchostName <List[String]>] [-Endpoint <String>]
 [-CertificatesName <List[String]>]
 [-CertificatesResourceType <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a vchost endpoint. Either the `VchostName` or `VchostId` query parameter is required.

## EXAMPLES

### Example 1
```powershell
New-Pfa2VchostEndpoint -Array $FlashArray -VchostName 'vchost-01' -Endpoint 'vchost-01-endpoint' -CertificatesName 'vchost-01-cert'
```

Creates a vchost endpoint on the array.

### Example 2
```powershell
New-Pfa2VchostEndpoint -Array $FlashArray -VchostName 'vchost-01'
```

Creates a vchost endpoint specifying only -VchostName.
