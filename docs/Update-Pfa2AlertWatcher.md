# Update-Pfa2AlertWatcher

## SYNOPSIS

(REST API 2.4+) Modify alert watcher

## SYNTAX

```
Update-Pfa2AlertWatcher [-Array <Rest2Api>] [-XRequestID <String>] -Name <String> [-Enabled <Boolean>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modify alert watcher email address by enabling or disabling it.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2AlertWatcher -Array $FlashArray -Name 'storage-ops@example.com' -Enabled $true
```

Enables email alert notifications for a watcher address.

### Example 2
```powershell
Update-Pfa2AlertWatcher -Array $FlashArray -Name 'storage-ops@example.com' -Enabled $false
```

Suspends notifications to a watcher without deleting it.
