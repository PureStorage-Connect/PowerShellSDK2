# New-Pfa2RealmConnectionsConnectionKeys

## SYNOPSIS

(REST API 2.43+) Create a realm connection key

## SYNTAX

```
New-Pfa2RealmConnectionsConnectionKeys [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-RealmIds <List[String]>]
 [-RealmNames <List[String]>] [-Type <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a connection key for a realm. Pass the key to `New-Pfa2RealmConnections` on the peer array to establish the connection.

## EXAMPLES

### Example 1
```powershell
New-Pfa2RealmConnectionsConnectionKeys -Array $FlashArray -RealmNames 'tenant-a' -Type 'replication'
```

Creates a connection key for a realm. Supply it to New-Pfa2RealmConnections on the peer array.

### Example 2
```powershell
(New-Pfa2RealmConnectionsConnectionKeys -Array $FlashArray -RealmNames 'tenant-a' -Type 'replication').ConnectionKey
```

Creates a realm connection key and returns just the key value.

### Example 3
```powershell
New-Pfa2RealmConnectionsConnectionKeys -Array $FlashArray -RealmNames 'tenant-a'
```

Creates a realm connection key specifying only -RealmNames.
