# Remove-Pfa2ResourceAccess

## SYNOPSIS

Delete a resource access configuration

## SYNTAX

```
Remove-Pfa2ResourceAccess [-Array <Rest2Api>] [-XRequestID <String>]
 [-Id <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes a resource access object.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2ResourceAccess -Array $FlashArray -Id $Grant.Id
```

Revokes a resource access grant by its ID.

### Example 2
```powershell
Get-Pfa2ResourceAccess -Array $FlashArray | ForEach-Object { Remove-Pfa2ResourceAccess -Array $FlashArray -Id $_.Id }
```

Revokes every outstanding resource access grant.

### Example 3
```powershell
Remove-Pfa2ResourceAccess -Array $FlashArray
```

Deletes the resource access grant.
