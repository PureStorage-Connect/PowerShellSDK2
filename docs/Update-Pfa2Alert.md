# Update-Pfa2Alert

## SYNOPSIS

(REST API 2.2+) Modify flagged state

## SYNTAX

```
Update-Pfa2Alert [-Array <Rest2Api>] [-XRequestID <String>]
 [-Id <List[String]>] [-Name <String>] [-Flagged <Boolean>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Modifies one or more alerts and display updated information about these alerts.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2Alert -Array $FlashArray -Name '42' -Flagged $true
```

Flags an alert so it stands out in the alert list and in monitoring queries.

### Example 2
```powershell
Update-Pfa2Alert -Array $FlashArray -Name '42' -Flagged $false
```

Clears the flag on an alert once it has been dealt with.

### Example 3
```powershell
Get-Pfa2Alert -Array $FlashArray -Filter "severity='critical'" | ForEach-Object { Update-Pfa2Alert -Array $FlashArray -Name $_.Name -Flagged $true }
```

Flags every open critical alert.
