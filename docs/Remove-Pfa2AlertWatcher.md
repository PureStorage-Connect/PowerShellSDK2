# Remove-Pfa2AlertWatcher

## SYNOPSIS

(REST API 2.4+) Delete alert watcher

## SYNTAX

```
Remove-Pfa2AlertWatcher [-Array <Rest2Api>] [-XRequestID <String>] -Name <String> [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Delete alert watcher email address from the list of alert watchers.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2AlertWatcher -Array $FlashArray -Name 'storage-ops@example.com'
```

Deletes the alert watcher named 'storage-ops@example.com'.

### Example 2
```powershell
Get-Pfa2AlertWatcher -Array $FlashArray -Filter "name='storage*'" | Remove-Pfa2AlertWatcher -Array $FlashArray
```

Deletes every alert watcher returned by the filter by piping the results into Remove-Pfa2AlertWatcher.
