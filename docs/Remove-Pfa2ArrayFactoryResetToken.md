# Remove-Pfa2ArrayFactoryResetToken

## SYNOPSIS

(REST API 2.4+) Delete a factory reset token

## SYNTAX

```
Remove-Pfa2ArrayFactoryResetToken [-Array <Rest2Api>] [-XRequestID <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes an existing token that could be used to perform a factory reset on the array.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2ArrayFactoryResetToken -Array $FlashArray
```

Revokes the outstanding factory reset token so the array can no longer be reset with it.

### Example 2
```powershell
Get-Pfa2ArrayFactoryResetToken -Array $FlashArray
```

Checks whether a factory reset token is currently outstanding before revoking it.
