# Remove-Pfa2SoftwareCheck

## SYNOPSIS

(REST API 2.9+) Delete a software check task

## SYNTAX

```
Remove-Pfa2SoftwareCheck [-Array <Rest2Api>] [-XRequestID <String>]
 [-SoftwareName <List[String]>]
 [-SoftwareVersion <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes a software check task specified by software name and version. The check task must be queued. If the check task is running or passed/failed then the task cannot be deleted.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2SoftwareCheck -Array $FlashArray -SoftwareName 'purity//fa' -SoftwareVersion '6.8.4'
```

Deletes the software upgrade check.

### Example 2
```powershell
Remove-Pfa2SoftwareCheck -Array $FlashArray -SoftwareName 'purity//fa'
```

Deletes the software upgrade check, also specifying -SoftwareName.

### Example 3
```powershell
Remove-Pfa2SoftwareCheck -Array $FlashArray -SoftwareVersion '6.8.4'
```

Deletes the software upgrade check, also specifying -SoftwareVersion.
