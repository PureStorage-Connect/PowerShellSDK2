# Remove-Pfa2Admin

## SYNOPSIS

(REST API 2.2+) Delete an administrator

## SYNTAX

```
Remove-Pfa2Admin [-Array <Rest2Api>] [-XRequestID <String>] [-Name <String>] [-ApiVersion <String>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Deletes the specified administrator.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2Admin -Array $FlashArray -Name $Name
```

Remove array administrator with name $Name.

### Example 2
```powershell
Remove-Pfa2Admin -Array $FlashArray -Name 'jsmith' -Confirm:$false
```

Deletes the array administrator named 'jsmith'.

### Example 3
```powershell
Get-Pfa2Admin -Array $FlashArray -Filter "name='jsmith*'" | Remove-Pfa2Admin -Array $FlashArray -Confirm:$false
```

Deletes every array administrator returned by the filter by piping the results into Remove-Pfa2Admin.
