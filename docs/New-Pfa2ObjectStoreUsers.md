# New-Pfa2ObjectStoreUsers

## SYNOPSIS

(REST API 2.26+) Create an object store user

## SYNTAX

```
New-Pfa2ObjectStoreUsers [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] -Name <String> [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates an object store user inside an object store account. Supply the qualified name `<account>/<user>`. Issue S3 credentials for the user with `New-Pfa2ObjectStoreAccessKeys`.

## EXAMPLES

### Example 1
```powershell
New-Pfa2ObjectStoreUsers -Array $FlashArray -Name 's3-account-01/reporting-user'
```

Creates an object store user inside an account. The name is qualified as <account>/<user>.

### Example 2
```powershell
New-Pfa2ObjectStoreUsers -Array $FlashArray -Name 's3-account-01/reporting-user' | ForEach-Object { New-Pfa2ObjectStoreAccessKeys -Array $FlashArray -UserName $_.Name }
```

Creates an object store user and immediately issues an access key for it.
