# Update-Pfa2PolicyUserGroupQuota

## SYNOPSIS

Modify user-group-quota policies

## SYNTAX

```
Update-Pfa2PolicyUserGroupQuota [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-Id <List[String]>] [-IgnoreUsage <Boolean>] [-Name <String>]
 [-PolicyName <String>] [-Enabled <Boolean>] [-ApiVersion <String>]
 [<CommonParameters>]
```

## DESCRIPTION

Modifies one or more user-group-quota policies. To enable a policy, set `Enabled=$True`. To disable a policy, set `Enabled=$False`. To rename a policy, set `PolicyName` to the new name. The `Id` or `Name` parameter is required, but they cannot be set together.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2PolicyUserGroupQuota -Array $FlashArray -Name 'user-quota-1t' -Enabled $true
```

Sets -Enabled on the user and group quota policy named 'user-quota-1t'.

### Example 2
```powershell
Update-Pfa2PolicyUserGroupQuota -Array $FlashArray -Name 'user-quota-1t' -PolicyName 'user-quota-1t'
```

Sets -PolicyName on the user and group quota policy named 'user-quota-1t'.

### Example 3
```powershell
Update-Pfa2PolicyUserGroupQuota -Array $FlashArray -Name 'user-quota-1t' -IgnoreUsage $true
```

Sets -IgnoreUsage on the user and group quota policy named 'user-quota-1t'.
