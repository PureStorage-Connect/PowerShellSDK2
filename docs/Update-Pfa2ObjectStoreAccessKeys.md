# Update-Pfa2ObjectStoreAccessKeys

## SYNOPSIS

(REST API 2.26+) Enable or disable an object store access key

## SYNTAX

```
Update-Pfa2ObjectStoreAccessKeys [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] -Name <String> [-Enabled <Boolean>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Enables or disables an S3 access key. Disabling a key stops it authenticating immediately while leaving it in place, which is the safe first step when rotating credentials.

## EXAMPLES

### Example 1
```powershell
Update-Pfa2ObjectStoreAccessKeys -Array $FlashArray -Name 'PSFBSAZRDKHUAAAAAAAA' -Enabled $false
```

Disables an access key without deleting it, which is the safe first step when rotating credentials.

### Example 2
```powershell
Update-Pfa2ObjectStoreAccessKeys -Array $FlashArray -Name 'PSFBSAZRDKHUAAAAAAAA' -Enabled $true
```

Re-enables a previously disabled access key.
