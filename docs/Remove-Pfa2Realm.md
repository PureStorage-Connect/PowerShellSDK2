# Remove-Pfa2Realm

## SYNOPSIS

Delete realms

## SYNTAX

```
Remove-Pfa2Realm [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-EradicateContents <Boolean>]
 [-Id <List[String]>] [-Name <String>] [-Eradicate] [-ApiVersion <String>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Deletes realms that have been destroyed and are pending eradication. Eradicated realms cannot be recovered. Realms are destroyed using the Update-Pfa2Realm method.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2Realm -Array $FlashArray -Name 'tenant-a' -Confirm:$false
```

Deletes the realm named 'tenant-a'.

### Example 2
```powershell
Remove-Pfa2Realm -Array $FlashArray -Name 'tenant-a' -Eradicate -Confirm:$false
```

Permanently eradicates the destroyed realm named 'tenant-a'. This bypasses the eradication pending period and cannot be undone.

### Example 3
```powershell
Get-Pfa2Realm -Array $FlashArray -Destroyed $true | Remove-Pfa2Realm -Array $FlashArray -Eradicate -Confirm:$false
```

Eradicates every realm that is already destroyed and pending eradication.
