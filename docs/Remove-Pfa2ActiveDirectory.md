# Remove-Pfa2ActiveDirectory

## SYNOPSIS

(REST API 2.3+) Delete Active Directory account

## SYNTAX

```
Remove-Pfa2ActiveDirectory [-Array <Rest2Api>] [-XRequestID <String>] [-LocalOnly <Boolean>] -Name <String>
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes one or more specified Active Directory accounts.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2ActiveDirectory -Array $FlashArray -Name 'ad-account-01'
```

Deletes the Active Directory account named 'ad-account-01'.

### Example 2
```powershell
Remove-Pfa2ActiveDirectory -Array $FlashArray -Name 'ad-account-01' -LocalOnly $true
```

Deletes the Active Directory account, also specifying -LocalOnly.
