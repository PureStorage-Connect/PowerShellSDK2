# Remove-Pfa2PolicySmbClientRule

## SYNOPSIS

(REST API 2.3+) Delete SMB client policy rules.

## SYNTAX

```
Remove-Pfa2PolicySmbClientRule [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>] [-Name <String>]
 [-PolicyId <List[String]>]
 [-PolicyName <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes one or more SMB client policy rules. The `PolicyId` or `PolicyName` parameter is required, but they cannot be set together.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2PolicySmbClientRule -Array $FlashArray -Name 'smb-default'
```

Deletes the SMB policy client rule named 'smb-default'.

### Example 2
```powershell
Remove-Pfa2PolicySmbClientRule -Array $FlashArray -Name 'smb-default' -PolicyName 'smb-default'
```

Deletes the SMB policy client rule, also specifying -PolicyName.
