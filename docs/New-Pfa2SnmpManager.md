# New-Pfa2SnmpManager

## SYNOPSIS

(REST API 2.4+) Create SNMP manager

## SYNTAX

```
New-Pfa2SnmpManager [-Array <Rest2Api>] [-XRequestID <String>] [-Name <String>] [-Host <String>]
 [-Notification <String>] [-Version <String>] [-V2cCommunity <String>] [-V3AuthPassphrase <String>]
 [-V3AuthProtocol <String>] [-V3PrivacyPassphrase <String>] [-V3PrivacyProtocol <String>] [-V3User <String>]
 [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Creates a Purity SNMP manager object that identifies a host (SNMP manager) and specifies the protocol attributes for communicating with it. Once a manager object is created, the transmission of SNMP traps is immediately enabled.

## EXAMPLES

### Example 1
```powershell
New-Pfa2SnmpManager -Array $FlashArray -Name 'snmp-mgr-01'
```

Creates an SNMP manager named 'snmp-mgr-01'.

### Example 2
```powershell
New-Pfa2SnmpManager -Array $FlashArray -Name 'snmp-mgr-01' -Host 'snmp-mgr-01' -Notification 'snmp-mgr-01'
```

Creates an SNMP manager and sets -Host and -Notification in the same call.
