# Remove-Pfa2ObjectStoreAccounts

## SYNOPSIS

(REST API 2.26+) Delete an object store account

## SYNTAX

```
Remove-Pfa2ObjectStoreAccounts [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-Id <List[String]>] [-Name <String>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Deletes an object store account. The account must not contain any buckets or object store users.

## EXAMPLES

### Example 1
```powershell
Remove-Pfa2ObjectStoreAccounts -Array $FlashArray -Name 's3-account-01'
```

Deletes the object store account named 's3-account-01'.

### Example 2
```powershell
Get-Pfa2ObjectStoreAccounts -Array $FlashArray -Filter "name='s3*'" | Remove-Pfa2ObjectStoreAccounts -Array $FlashArray
```

Deletes every object store account returned by the filter by piping the results into Remove-Pfa2ObjectStoreAccounts.
