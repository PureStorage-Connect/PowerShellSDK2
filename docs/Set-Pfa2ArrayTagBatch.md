# Set-Pfa2ArrayTagBatch

## SYNOPSIS

Update tags

## SYNTAX

```
Set-Pfa2ArrayTagBatch [-Array <Rest2Api>] [-XRequestID <String>]
 [-ContextName <List[String]>]
 [-TagKey <List[String]>]
 [-TagNamespace <List[String]>]
 [-TagValue <List[String]>] [-ApiVersion <String>] [<CommonParameters>]
```

## DESCRIPTION

Updates tags.

## EXAMPLES

### Example 1
```powershell
Set-Pfa2ArrayTagBatch -Array $FlashArray -TagKey 'environment' -TagValue 'production'
```

Applies the tag `environment=production` to the array.

### Example 2
```powershell
Set-Pfa2ArrayTagBatch -Array $FlashArray -TagKey 'environment', 'owner' -TagValue 'production', 'storage-ops'
```

Applies two tags to the array in one call. -TagKey and -TagValue are positional lists, matched pairwise.
